# GW-005: Circuit Breaker

## User Story
> As a Gateway, I open the circuit breaker on downstream service failures so that failing services have time to recover and the system remains stable.

## API

### Resilience4j Configuration

| Setting | Value |
|---------|-------|
| Failure Rate Threshold | 50% |
| Slow Request Threshold | 80% |
| Slow Call Duration | 2 seconds |
| Wait Duration in Open State | 30 seconds |
| Permitted Calls in Half-Open | 10 |
| Sliding Window Size | 100 calls |
| Minimum Number of Calls | 20 |

### Circuit State Transitions

```
CLOSED ───(failure rate > 50%)───► OPEN
   ▲                                  │
   │                                  │ (wait 30s)
   │                                  ▼
   │◄─────(success rate > 50%)── HALF-OPEN
   │                                  │
   └──────────────────────────────────┘
```

### Service Unavailable Response (503)

```json
{
  "error": "SERVICE_UNAVAILABLE",
  "msg": "Service temporarily unavailable",
  "service": "product-service",
  "retryAfter": 30
}
```

### Example - Circuit Opens

**Request:**
```http
GET /api/v1/products/123 HTTP/1.1
Host: gateway:8091
```

**product-service is down (503):**
```json
{
  "error": "SERVICE_UNAVAILABLE",
  "msg": "Service temporarily unavailable",
  "service": "product-service",
  "retryAfter": 30
}
```

### Health Endpoint Shows Circuit State

```http
GET /health HTTP/1.1
Host: gateway:8091
```

**Response:**
```json
{
  "status": "UP",
  "components": {
    "product-service": {
      "status": "DOWN",
      "circuitState": "OPEN"
    },
    "user-service": {
      "status": "UP",
      "circuitState": "CLOSED"
    }
  }
}
```

---

## Acceptance Criteria

- [ ] Circuit opens after 50% failure rate in sliding window
- [ ] Circuit opens for slow requests (>2s duration, >80% threshold)
- [ ] Returns 503 SERVICE_UNAVAILABLE when circuit is open
- [ ] Circuit transitions to HALF-OPEN after 30 seconds
- [ ] Circuit closes after successful calls in HALF-OPEN state
- [ ] Each downstream service has independent circuit breaker
- [ ] Circuit state visible in /health endpoint
