# GW-010: Health Check

## User Story
> As an operator, I can check the Gateway health so that I can monitor its status and the health of downstream services.

## API

### GET /health

**Request:**
```http
GET /health HTTP/1.1
Host: gateway:8091
```

---

## Acceptance Criteria

- [ ] GET /health returns 200 when gateway is healthy
- [ ] GET /health returns 503 when any downstream service is DOWN
- [ ] Response includes gateway uptime
- [ ] Response includes status of all downstream services
- [ ] Response includes circuit breaker state for each service
- [ ] Response includes Consul registration status
- [ ] Health check does not require authentication
