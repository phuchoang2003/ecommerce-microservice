# GW-011: List Routes

## User Story
> As an operator, I can retrieve all configured routes via GET /routes so that I can understand the current routing configuration.

## API

Host: gateway:8091
Authorization: Bearer <admin-token>

### GET /routes/{serviceId}

**Request:**
```http
GET /routes/user-service HTTP/1.1
Host: gateway:8091
Authorization: Bearer <admin-token>
```

**Response (200):**
```json
{
  "id": "user-service",
  "path": "/api/v1/users/**",
  "targetUri": "http://user-service:8081",
  "predicates": ["Path=/api/v1/users/**"],
  "filters": ["JwtValidationFilter", "RateLimitFilter", "HeaderForwardFilter"],
  "authRequired": true,
  "roles": ["BUYER", "SELLER", "ADMIN"]
}
```

---

## Acceptance Criteria

- [ ] GET /routes returns all 9 configured routes
- [ ] GET /routes requires ADMIN role authentication
- [ ] Response includes route id, path, and targetUri
- [ ] Response includes applied filters for each route
- [ ] Response includes authRequired flag
- [ ] Response includes required roles for each route
- [ ] GET /routes/{serviceId} returns single route details
- [ ] GET /routes/{serviceId} returns 404 for unknown service
