# GW-020: Register Service

## User Story
> As a Gateway, I auto-register with Consul on startup so that downstream services can discover me through service discovery.

## API

### Consul Registration

**Registration Details:**
| Field | Value |
|-------|-------|
| Service ID | gateway-{hostname}-{port} |
| Service Name | gateway |
| Port | 8091 |
| Health Check | http://localhost:8091/health |
| Tags | gateway, api-gateway, spring-cloud |

### Startup Flow

```
Gateway Application Starts
        │
        ▼
┌──────────────────┐
│  Consul Client   │
│  Auto-Config     │
└──────────────────┘
        │
        ▼
┌──────────────────┐
│  Register with   │
│  Consul Agent     │
└──────────────────┘
        │
        ▼
┌──────────────────┐
│  Start Health    │
│  Check Polling   │
└──────────────────┘
```

---

## Acceptance Criteria

- [ ] Gateway registers with Consul on application startup
- [ ] Service ID is unique (includes hostname and port)
- [ ] Health check is registered with Consul
- [ ] Health check polls /health endpoint
- [ ] Tags include "gateway", "api-gateway", "spring-cloud"
- [ ] Registration metadata includes version
- [ ] Gateway remains registered while application is running
- [ ] Fails gracefully if Consul is unavailable at startup
