# PAY-001: Create Payment Intent

## User Story

**As a** customer or service
**I want to** create a Stripe payment intent
**So that** I can initiate a payment for an order

## API

### POST /api/v1/payments/intent

**Request Headers:**
```
Content-Type: application/json
Authorization: Bearer {token}
X-Idempotency-Key: {uuid}
```

**Request Body:**
```json
{
  "orderId": "ord_1234567890",
  "amount": 9999,
  "currency": "usd",
  "customerId": "cus_abc123",
  "metadata": {
    "orderReference": "ORD-2024-001"
  }
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| orderId | string | Yes | Unique order identifier |
| amount | integer | Yes | Amount in smallest currency unit (cents) |
| currency | string | Yes | ISO 4217 currency code |
| customerId | string | No | Stripe customer ID |
| metadata | object | No | Additional key-value metadata |

**Response (201 Created):**
```json
{
  "paymentIntentId": "pi_3abc123def456",
  "clientSecret": "pi_3abc123def456_secret_xyz789",
  "orderId": "ord_1234567890",
  "amount": 9999,
  "currency": "usd",
  "status": "requires_payment_method",
  "createdAt": "2026-04-04T10:30:00Z"
}
```

## Acceptance Criteria

- [ ] Payment intent is created in Stripe with correct amount and currency
- [ ] Client secret is returned for frontend payment completion
- [ ] Order ID is stored in payment intent metadata
- [ ] Idempotency key prevents duplicate payment intents
- [ ] Amount is validated (must be positive, within limits)
- [ ] Currency is validated against supported currencies
- [ ] Response includes Stripe payment intent ID and client secret
