# PAY-002: Get Payment

## User Story

**As a** customer or service
**I want to** retrieve payment details by payment ID
**So that** I can check the status of a specific payment

## API

### GET /api/v1/payments/{paymentId}

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| paymentId | string | The payment identifier (e.g., pi_3abc123def456) |

**Request Headers:**
```
Authorization: Bearer {token}
```

**Response (200 OK):**
```json
{
  "paymentId": "pi_3abc123def456",
  "orderId": "ord_1234567890",
  "amount": 9999,
  "currency": "usd",
  "status": "succeeded",
  "customerId": "cus_abc123",
  "paymentMethod": "card_1abc123",
  "description": "Payment for order ORD-2024-001",
  "metadata": {
    "orderReference": "ORD-2024-001"
  },
  "createdAt": "2026-04-04T10:30:00Z",
  "updatedAt": "2026-04-04T10:31:00Z"
}
```

**Status Values:** `requires_payment_method`, `requires_confirmation`, `requires_action`, `processing`, `succeeded`, `failed`, `canceled`

## Acceptance Criteria

- [ ] Payment details are returned for valid payment ID
- [ ] 404 error returned for non-existent payment ID
- [ ] Response includes current payment status from Stripe
- [ ] Metadata from payment creation is preserved
- [ ] Timestamps (createdAt, updatedAt) are included
