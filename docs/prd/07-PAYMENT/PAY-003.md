# PAY-003: Get Payment Intent

## User Story

**As a** customer or service
**I want to** retrieve a payment intent by intent ID
**So that** I can check the status of a payment intent before confirmation

## API

### GET /api/v1/payments/intent/{intentId}

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| intentId | string | The Stripe payment intent ID (e.g., pi_3abc123def456) |

**Request Headers:**
```
Authorization: Bearer {token}
```

**Response (200 OK):**
```json
{
  "paymentIntentId": "pi_3abc123def456",
  "orderId": "ord_1234567890",
  "amount": 9999,
  "currency": "usd",
  "status": "requires_payment_method",
  "clientSecret": "pi_3abc123def456_secret_xyz789",
  "nextAction": null,
  "createdAt": "2026-04-04T10:30:00Z",
  "lastPaymentError": null
}
```

**Status Values:** `requires_payment_method`, `requires_confirmation`, `requires_action`, `processing`, `succeeded`, `failed`, `canceled`

## Acceptance Criteria

- [ ] Payment intent details are returned for valid intent ID
- [ ] 404 error returned for non-existent payment intent
- [ ] Client secret is included in response
- [ ] Status reflects current Stripe payment intent state
- [ ] Last payment error is included if any
- [ ] Next action is included if payment requires additional steps
