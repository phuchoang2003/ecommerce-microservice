# PAY-004: Cancel Payment

## User Story

**As a** customer or administrator
**I want to** cancel a payment
**So that** I can void a payment that has not been completed or captured

## API

### POST /api/v1/payments/{paymentId}/cancel

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| paymentId | string | The payment identifier (e.g., pi_3abc123def456) |

**Request Headers:**
```
Authorization: Bearer {token}
```

**Response (200 OK):**
```json
{
  "paymentId": "pi_3abc123def456",
  "orderId": "ord_1234567890",
  "status": "canceled",
  "canceledAt": "2026-04-04T10:35:00Z",
  "cancellationReason": "requested_by_customer"
}
```

**Cancellation Reasons:** `requested_by_customer`, `duplicate`, `fraudulent`

## Acceptance Criteria

- [ ] Payment is canceled in Stripe for cancelable payments
- [ ] 400 error returned if payment cannot be canceled (e.g., already succeeded)
- [ ] 404 error returned for non-existent payment
- [ ] Cancellation reason is recorded
- [ ] Response includes final payment status
- [ ] Order service is notified of cancellation
