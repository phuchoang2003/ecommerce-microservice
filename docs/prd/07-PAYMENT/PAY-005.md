# PAY-005: List Payments

## User Story

**As a** administrator or service
**I want to** list payments with filtering and pagination
**So that** I can view payment history and search for specific payments

## API

### GET /api/v1/payments

**Query Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| page | integer | No | Page number (default: 1) |
| limit | integer | No | Items per page (default: 20, max: 100) |
| orderId | string | No | Filter by order ID |
| customerId | string | No | Filter by customer ID |
| status | string | No | Filter by payment status |
| fromDate | string | No | Filter payments created after (ISO 8601) |
| toDate | string | No | Filter payments created before (ISO 8601) |

**Request Headers:**
```
Authorization: Bearer {token}
```

**Response (200 OK):**
```json
{
  "data": [
    {
      "paymentId": "pi_3abc123def456",
      "orderId": "ord_1234567890",
      "amount": 9999,
      "currency": "usd",
      "status": "succeeded",
      "customerId": "cus_abc123",
      "createdAt": "2026-04-04T10:30:00Z"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "totalItems": 150,
    "totalPages": 8
  }
}
```

## Acceptance Criteria

- [ ] Payments are returned with pagination metadata
- [ ] Filtering works correctly for all filter parameters
- [ ] Results are sorted by createdAt descending (newest first)
- [ ] Empty array returned when no payments match filters
- [ ] Invalid filter values return 400 error
- [ ] Pagination limits are enforced (max 100 per page)
