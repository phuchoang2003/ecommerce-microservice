# PAY-010: Webhook Handler

## User Story

**As a** Stripe integration
**I want to** receive and process Stripe webhook events
**So that** the payment service can update payment statuses based on Stripe events

## API

### POST /api/v1/payments/webhook

**Request Headers:**
```
Content-Type: application/json
Stripe-Signature: {signature}
```

**Request Body (Stripe Event):**
```json
{
  "id": "evt_1234567890",
  "type": "payment_intent.succeeded",
  "data": {
    "object": {
      "id": "pi_3abc123def456",
      "object": "payment_intent",
      "amount": 9999,
      "currency": "usd",
      "status": "succeeded",
      "metadata": {
        "orderId": "ord_1234567890"
      }
    }
  },
  "created": 1712221800
}
```

**Supported Event Types:**
- `payment_intent.succeeded`
- `payment_intent.payment_failed`
- `payment_intent.canceled`
- `charge.refunded`
- `charge.dispute.created`

**Response (200 OK):**
```json
{
  "received": true,
  "eventId": "evt_1234567890"
}
```

## Acceptance Criteria

- [ ] Webhook signature is verified using Stripe webhook secret
- [ ] Invalid signatures return 400 error
- [ ] Duplicate events are handled idempotently
- [ ] Payment status is updated based on event type
- [ ] Order service is notified of successful payments
- [ ] Refund events update refund records
- [ ] 500 errors during processing trigger Stripe retry
- [ ] Event logging for audit trail
