# PAY-020: Create Refund

## User Story

**As a** administrator or automated system
**I want to** create a full refund for a payment
**So that** customers can receive their money back for cancelled or disputed orders

## API

### POST /api/v1/payments/{paymentId}/refund

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| paymentId | string | The payment identifier (e.g., pi_3abc123def456) |

**Request Headers:**
```
Authorization: Bearer {token}
Content-Type: application/json
```

**Request Body:**
```json
{
  "reason": "requested_by_customer"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| reason | string | Yes | Reason for refund |

**Refund Reasons:** `duplicate`, `fraudulent`, `requested_by_customer`

**Response (201 Created):**
```json
{
  "refundId": "re_3abc123def456",
  "paymentId": "pi_3abc123def456",
  "amount": 9999,
  "currency": "usd",
  "status": "succeeded",
  "reason": "requested_by_customer",
  "createdAt": "2026-04-04T11:00:00Z"
}
```

## Acceptance Criteria

- [ ] Full refund is created in Stripe for the payment
- [ ] Refund amount equals original payment amount
- [ ] 400 error returned if payment cannot be refunded
- [ ] 404 error returned for non-existent payment
- [ ] Refund ID is returned in response
- [ ] Refund reason is recorded
- [ ] Payment status is updated after refund
- [ ] Order service is notified of refund
