# PAY-021: Partial Refund

## User Story

**As a** administrator or customer support
**I want to** create a partial refund for a payment
**So that** customers can receive a portion of their money back for partial order cancellations

## API

### POST /api/v1/payments/{paymentId}/refund

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| paymentId | string | The payment identifier (e.g., pi_3abc123def456) |

**Request Headers:**
```
Authorization: Bearer {token}
Content-Type: application/json
```

**Request Body:**
```json
{
  "amount": 4999,
  "reason": "requested_by_customer"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| amount | integer | Yes | Amount to refund in smallest currency unit |
| reason | string | Yes | Reason for refund |

**Refund Reasons:** `duplicate`, `fraudulent`, `requested_by_customer`

**Response (201 Created):**
```json
{
  "refundId": "re_3abc123def456",
  "paymentId": "pi_3abc123def456",
  "amount": 4999,
  "currency": "usd",
  "status": "succeeded",
  "reason": "requested_by_customer",
  "createdAt": "2026-04-04T11:00:00Z"
}
```

## Acceptance Criteria

- [ ] Partial refund is created in Stripe with specified amount
- [ ] Amount must be less than or equal to remaining refundable amount
- [ ] Amount must be positive
- [ ] 400 error returned if amount exceeds refundable balance
- [ ] 404 error returned for non-existent payment
- [ ] Multiple partial refunds can be processed
- [ ] Total refunds cannot exceed original payment amount
- [ ] Response includes updated refund balance information
