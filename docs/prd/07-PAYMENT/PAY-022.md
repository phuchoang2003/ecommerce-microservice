# PAY-022: List Refunds

## User Story

**As a** administrator or customer support
**I want to** list all refunds for a payment
**So that** I can view refund history and track partial refund amounts

## API

### GET /api/v1/payments/{paymentId}/refunds

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| paymentId | string | The payment identifier (e.g., pi_3abc123def456) |

**Query Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| page | integer | No | Page number (default: 1) |
| limit | integer | No | Items per page (default: 20, max: 100) |

**Request Headers:**
```
Authorization: Bearer {token}
```

**Response (200 OK):**
```json
{
  "data": [
    {
      "refundId": "re_3abc123def456",

      "amount": 4999,

      "createdAt": "2026-04-04T11:00:00Z"
    },
    {
```

## Acceptance Criteria

- [ ] All refunds for the payment are returned
- [ ] Refunds are sorted by createdAt descending
- [ ] Summary includes total refunded and remaining amount
- [ ] 404 error returned for non-existent payment
- [ ] Empty array returned if no refunds exist
- [ ] Pagination works correctly
