# PAY-030: Get Escrow

## User Story

**As a** customer, seller, or administrator
**I want to** view the escrow status for an order
**So that** I can track when funds are held, released, or refunded

## API

### GET /api/v1/payments/escrow/{orderId}

**Path Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| orderId | string | The order identifier (e.g., ord_1234567890) |

**Request Headers:**
```
Authorization: Bearer {token}
```

**Response (200 OK):**
```json
{
  "orderId": "ord_1234567890",
  "paymentId": "pi_3abc123def456",
  "escrowStatus": "held",
  "amount": 9999,
  "currency": "usd",
  "heldAt": "2026-04-04T10:30:00Z",
  "releaseAt": "2026-04-11T10:30:00Z",
  "autoRelease": true,
  "timeline": [
    {
      "event": "payment_succeeded",
      "timestamp": "2026-04-04T10:30:00Z",
      "description": "Funds held in escrow"
    },
    {
      "event": "delivery_confirmed",
      "timestamp": "2026-04-07T10:30:00Z",
      "description": "Delivery confirmed, awaiting auto-release"
    }
  ]
}
```

**Escrow Status Values:** `pending`, `held`, `released`, `refunded`, `expired`

## Acceptance Criteria

- [ ] Escrow details are returned for valid order ID
- [ ] 404 error returned for non-existent order or escrow
- [ ] Timeline shows complete escrow history
- [ ] Auto-release date is calculated correctly (7 days default)
- [ ] Remaining time until release is included
- [ ] Current escrow status is accurate
