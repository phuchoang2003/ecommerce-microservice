# PAY-031: Manual Release

## User Story

**As an** administrator
**I want to** manually release escrow funds
**So that** I can handle special cases where automatic release should be bypassed

## API

### POST /api/v1/admin/escrow/release

**Request Headers:**
```
Authorization: Bearer {token}
Content-Type: application/json
X-Admin-Reason: {reason}
```

**Request Body:**
```json
{
  "orderId": "ord_1234567890",
  "reason": "Order delivered early, releasing funds",
  "notifyParties": true
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| orderId | string | Yes | The order identifier |
| reason | string | Yes | Admin reason for manual release |
| notifyParties | boolean | No | Notify buyer and seller (default: true) |

**Response (200 OK):**
```json
{
  "orderId": "ord_1234567890",
  "paymentId": "pi_3abc123def456",
  "escrowStatus": "released",
  "releasedAt": "2026-04-04T14:00:00Z",
  "releaseReason": "manual_admin_release",
  "adminReason": "Order delivered early, releasing funds",
  "releasedTo": {
    "sellerId": "seller_abc123",
    "amount": 9500,
    "currency": "usd"
  },
  "fees": {
    "platformFee": 499,
    "currency": "usd"
  }
}
```

## Acceptance Criteria

- [ ] Only admin role can access this endpoint
- [ ] Escrow is released immediately in Stripe
- [ ] Admin reason is logged for audit
- [ ] Buyer and seller are notified if notifyParties is true
- [ ] Platform fees are calculated correctly
- [ ] 400 error returned if escrow cannot be released
- [ ] 404 error returned for non-existent escrow
- [ ] Idempotent: re-releasing returns success but no duplicate release
