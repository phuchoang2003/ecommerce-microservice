# REV-001: Submit Review

## User Story
As a customer, I want to submit a review for a product after my order has been delivered, so that I can share my experience and help other customers make informed decisions. Each product per order can only be reviewed once.

## API

**Endpoint:** `POST /api/v1/reviews`

**Request Body:**
```json
{
  "productId": "prod-12345",
  "orderId": "ord-67890",
  "rating": 5,
  "title": "Great product!",
  "content": "The product exceeded my expectations. Fast delivery and excellent quality.",
  "images": ["https://example.com/image1.jpg", "https://example.com/image2.jpg"],
  "videos": []
}
```

**Response (201 Created):**
```json
{
  "id": "rev-001",
  "productId": "prod-12345",
  "orderId": "ord-67890",
  "userId": "user-123",
  "rating": 5,
  "title": "Great product!",
  "content": "The product exceeded my expectations. Fast delivery and excellent quality.",
  "images": ["https://example.com/image1.jpg", "https://example.com/image2.jpg"],
  "videos": [],
  "status": "PUBLISHED",
  "createdAt": "2026-04-04T10:30:00Z",
  "updatedAt": "2026-04-04T10:30:00Z"
}
```

## Acceptance Criteria

- [ ] User must be authenticated to submit a review
- [ ] Order must be in DELIVERED status
- [ ] One review per product per order per user (unique constraint)
- [ ] Rating must be between 1 and 5
- [ ] Title is optional, max 200 characters
- [ ] Content is required, min 10 characters, max 2000 characters
- [ ] Maximum 10 images allowed
- [ ] Maximum 2 videos allowed
- [ ] Review is created with PUBLISHED status by default
- [ ] Returns 400 if eligibility check fails
- [ ] Returns 409 if review already exists for this product-order combination
