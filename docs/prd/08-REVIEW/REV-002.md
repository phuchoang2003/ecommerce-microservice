# REV-002: Get Product Reviews

## User Story
As a user, I want to view all reviews for a specific product, so that I can read other customers' experiences and make informed purchasing decisions.

## API

**Endpoint:** `GET /api/v1/reviews/product/{productId}`

**Path Parameters:**
- `productId` (string, required): The product identifier

**Query Parameters:**
- `page` (integer, optional, default: 0): Page number
- `size` (integer, optional, default: 10, max: 50): Page size
- `sort` (string, optional, default: "createdAt,desc"): Sort field and direction

**Response (200 OK):**
```json
{
  "content": [
    {
      "id": "rev-001",
      "productId": "prod-12345",
      "userId": "user-123",
      "userName": "John D.",
      "rating": 5,
      "title": "Great product!",
      "content": "The product exceeded my expectations.",
      "images": ["https://example.com/image1.jpg"],
      "videos": [],
      "helpfulCount": 15,
      "verified": true,
      "status": "PUBLISHED",
      "createdAt": "2026-04-04T10:30:00Z"
    }
  ],
  "page": 0,
  "size": 10,
  "totalElements": 42,
  "totalPages": 5
}
```

## Acceptance Criteria

- [ ] Returns only PUBLISHED reviews
- [ ] Only shows reviews for the specified product
- [ ] Supports pagination with configurable page size
- [ ] Supports sorting by createdAt, rating, helpfulCount
- [ ] Includes user display name (anonymized)
- [ ] Indicates if review is from a verified purchase
- [ ] Returns empty list for products with no reviews
- [ ] Returns 404 for invalid productId format
