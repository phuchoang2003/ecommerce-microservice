# REV-003: Update Review

## User Story
As a customer, I want to update my review, so that I can correct or add information based on my continued use of the product.

## API

**Endpoint:** `PUT /api/v1/reviews/{reviewId}`

**Path Parameters:**
- `reviewId` (string, required): The review identifier

**Request Body:**
```json
{
  "rating": 4,
  "title": "Updated: Great product!",
  "content": "After using this for a month, I can say the quality is excellent but delivery was slow.",
  "images": ["https://example.com/image1.jpg"],
  "videos": []
}
```

**Response (200 OK):**
```json
{
  "id": "rev-001",
  "productId": "prod-12345",
  "orderId": "ord-67890",
  "userId": "user-123",
  "rating": 4,
  "title": "Updated: Great product!",
  "content": "After using this for a month, I can say the quality is excellent but delivery was slow.",
  "images": ["https://example.com/image1.jpg"],
  "videos": [],
  "status": "PUBLISHED",
  "createdAt": "2026-04-04T10:30:00Z",
  "updatedAt": "2026-04-05T14:20:00Z"
}
```

## Acceptance Criteria

- [ ] User must be authenticated
- [ ] User can only update their own reviews
- [ ] Returns 403 if user does not own the review
- [ ] Returns 404 if review does not exist
- [ ] Rating must be between 1 and 5
- [ ] Content is required, min 10 characters, max 2000 characters
- [ ] Title is optional, max 200 characters
- [ ] Maximum 10 images allowed
- [ ] Maximum 2 videos allowed
- [ ] Updates the updatedAt timestamp
- [ ] Review status remains PUBLISHED after update
