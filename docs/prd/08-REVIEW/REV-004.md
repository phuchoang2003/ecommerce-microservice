# REV-004: Delete Review

## User Story
As a customer, I want to delete my review, so that I can remove feedback if I no longer wish to share it.

## API

**Endpoint:** `DELETE /api/v1/reviews/{reviewId}`

**Path Parameters:**
- `reviewId` (string, required): The review identifier

**Response (204 No Content)**

No response body.

## Acceptance Criteria

- [ ] User must be authenticated
- [ ] User can only delete their own reviews
- [ ] Returns 403 if user does not own the review
- [ ] Returns 404 if review does not exist
- [ ] Review is soft deleted (marked as DELETED status)
- [ ] Returns 204 on successful deletion
- [ ] Seller response is also removed when review is deleted
