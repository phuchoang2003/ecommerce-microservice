# REV-005: Get My Reviews

## User Story
As a customer, I want to view all my submitted reviews, so that I can track my feedback history and manage my contributions.

## API

**Endpoint:** `GET /api/v1/reviews/me`

**Query Parameters:**
- `page` (integer, optional, default: 0): Page number
- `size` (integer, optional, default: 10, max: 50): Page size
- `status` (string, optional): Filter by status (PUBLISHED, HIDDEN, DELETED)
- `productId` (string, optional): Filter by product

**Response (200 OK):**
```json

      "id": "rev-001",
      "productId": "prod-12345",
```

## Acceptance Criteria

- [ ] User must be authenticated
- [ ] Returns only reviews belonging to the authenticated user
- [ ] Supports pagination
- [ ] Supports filtering by status
- [ ] Supports filtering by productId
- [ ] Includes product name for context
- [ ] Includes seller response if exists
- [ ] Returns empty list if user has no reviews
