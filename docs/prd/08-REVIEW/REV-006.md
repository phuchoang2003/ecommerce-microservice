# REV-006: Check Eligibility

## User Story
As a customer, I want to check if I am eligible to review a product, so that I know whether I can submit a review before attempting to create one.

## API

**Endpoint:** `GET /api/v1/reviews/eligibility/{productId}`

**Path Parameters:**
- `productId` (string, required): The product identifier

**Response (200 OK):**
```json
{
  "eligible": true,
  "reason": "ORDER_DELIVERED",
  "orderId": "ord-67890",
  "msg": "You can submit a review for this product."
}
```

**Response (200 OK - Not Eligible):**
```json
{
  "eligible": false,
  "reason": "ALREADY_REVIEWED",
  "orderId": "ord-67890",
  "existingReviewId": "rev-001",
  "msg": "You have already reviewed this product for this order."
}
```

## Acceptance Criteria

- [ ] User must be authenticated
- [ ] Returns eligible=true if user has a delivered order containing the product and no existing review
- [ ] Returns eligible=false with reason ALREADY_REVIEWED if user already reviewed this product for the order
- [ ] Returns eligible=false with reason NO_PURCHASE if user has not purchased the product
- [ ] Returns eligible=false with reason ORDER_NOT_DELIVERED if order is not delivered
- [ ] Returns orderId when eligible or when previously reviewed
- [ ] Returns existingReviewId when not eligible due to existing review
