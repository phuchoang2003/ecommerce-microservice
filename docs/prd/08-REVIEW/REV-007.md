# REV-007: Report Review

## User Story
As a user, I want to report inappropriate reviews, so that I can help maintain review quality and flag content that violates guidelines.

## API

**Endpoint:** `POST /api/v1/reviews/{reviewId}/report`

**Path Parameters:**
- `reviewId` (string, required): The review identifier

**Request Body:**
```json
{
  "reason": "SPAM",
  "description": "This review contains promotional content for a competitor product."
}
```

**Reason Options:**
- `SPAM` - Promotional or irrelevant content
- `FAKE` - Fabricated or deceptive review
- `OFFENSIVE` - Contains offensive language
- `HARASSMENT` - Targets a specific individual or group
- `IRRELEVANT` - Not related to the product
- `OTHER` - Other issue (description required)

**Response (201 Created):**
```json
{
  "reportId": "rpt-001",
  "reviewId": "rev-001",
  "userId": "user-456",
  "reason": "SPAM",
  "description": "This review contains promotional content for a competitor product.",
  "status": "PENDING",
  "createdAt": "2026-04-04T11:00:00Z"
}
```

## Acceptance Criteria

- [ ] User must be authenticated
- [ ] User cannot report their own review
- [ ] Returns 400 if reason is OTHER and description is empty
- [ ] Returns 404 if review does not exist
- [ ] Returns 409 if user has already reported this review
- [ ] One user can only report a review once
- [ ] Report is created with PENDING status
- [ ] Returns 201 on successful report submission
