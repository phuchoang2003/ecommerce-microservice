# REV-008: Vote Helpful

## User Story
As a user, I want to vote on reviews as helpful, so that high-quality reviews are surfaced and other customers can easily find useful feedback.

## API

**Endpoint:** `POST /api/v1/reviews/{reviewId}/vote`

**Path Parameters:**
- `reviewId` (string, required): The review identifier

**Request Body:**
```json
{
  "helpful": true
}
```

**Response (200 OK):**
```json
{
  "reviewId": "rev-001",
  "helpfulCount": 16,
  "userVote": true
}
```

## Acceptance Criteria

- [ ] User must be authenticated
- [ ] User cannot vote on their own review
- [ ] Returns 404 if review does not exist
- [ ] Returns 400 if review is not PUBLISHED
- [ ] Vote toggles: voting helpful=true when already helpful removes the vote
- [ ] Each user can only have one vote per review
- [ ] helpfulCount is updated in real-time
- [ ] Returns current helpfulCount and user's vote status
