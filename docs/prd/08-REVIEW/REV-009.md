# REV-009: Get Review Summary

## User Story
As a user, I want to see a summary of product reviews, so that I can quickly understand the overall sentiment and rating distribution without reading all individual reviews.

## API

**Endpoint:** `GET /api/v1/reviews/product/{productId}/summary`

**Path Parameters:**
- `productId` (string, required): The product identifier

**Response (200 OK):**
```json
{
  "productId": "prod-12345",
  "averageRating": 4.3,
  "totalReviews": 42,
  "ratingDistribution": {
    "1": 2,
    "2": 3,
    "3": 5,
    "4": 12,
    "5": 20
  },
  "withImages": 15,
  "withVideos": 3,
  "verifiedReviews": 38,
  "recentReviews": [
    {
      "id": "rev-001",
      "rating": 5,
      "title": "Great product!",
      "userName": "John D.",
      "createdAt": "2026-04-04T10:30:00Z"
    }
  ]
}
```

## Acceptance Criteria

- [ ] Returns average rating to one decimal place
- [ ] Returns total count of PUBLISHED reviews only
- [ ] Returns rating distribution for 1-5 stars
- [ ] Returns count of reviews with images
- [ ] Returns count of reviews with videos
- [ ] Returns count of verified purchase reviews
- [ ] Returns up to 3 most recent reviews for preview
- [ ] Returns zeros/defaults if no reviews exist
