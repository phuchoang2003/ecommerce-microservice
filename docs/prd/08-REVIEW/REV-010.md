# REV-010: Seller Respond

## User Story
As a seller, I want to respond to reviews on my products, so that I can address customer concerns, thank satisfied customers, and demonstrate my commitment to customer service.

## API

**Endpoint:** `POST /api/v1/reviews/{reviewId}/response`

**Path Parameters:**
- `reviewId` (string, required): The review identifier

**Request Body:**
```json
{
  "content": "Thank you for your positive feedback! We're glad you enjoyed your purchase. We look forward to serving you again."
}
```

**Response (201 Created):**
```json
{
  "responseId": "resp-001",
  "reviewId": "rev-001",
  "sellerId": "seller-789",
  "content": "Thank you for your positive feedback! We're glad you enjoyed your purchase.",
  "createdAt": "2026-04-04T12:00:00Z",
  "updatedAt": "2026-04-04T12:00:00Z"
}
```

## Acceptance Criteria

- [ ] User must be authenticated and be the seller of the reviewed product
- [ ] Returns 403 if user is not the seller of the product
- [ ] Returns 404 if review does not exist
- [ ] Content is required, min 10 characters, max 1000 characters
- [ ] Only one seller response per review allowed
- [ ] Updating an existing response is not supported (must delete and create new)
- [ ] Seller can only respond to PUBLISHED reviews
- [ ] Returns 409 if response already exists
