# REV-011: Admin List Reviews

## User Story
As an admin, I want to list all reviews with filtering options, so that I can manage review content and monitor review quality across the platform.

## API

**Endpoint:** `GET /api/v1/admin/reviews`

**Query Parameters:**
- `page` (integer, optional, default: 0): Page number
- `size` (integer, optional, default: 20, max: 100): Page size
- `status` (string, optional): Filter by status (PUBLISHED, HIDDEN, DELETED, PENDING_MODERATION)
- `productId` (string, optional): Filter by product
- `userId` (string, optional): Filter by user
- `sellerId` (string, optional): Filter by seller
- `minRating` (integer, optional): Minimum rating
- `maxRating` (integer, optional): Maximum rating
- `hasReports` (boolean, optional): Filter reviews with reports
- `startDate` (string, optional): Filter reviews created after this date (ISO 8601)
- `endDate` (string, optional): Filter reviews created before this date (ISO 8601)

## Acceptance Criteria

- [ ] User must have ADMIN role
- [ ] Returns reviews across all products and sellers
- [ ] Supports all filtering parameters
- [ ] Supports pagination with configurable page size
- [ ] Includes product name and seller name for context
- [ ] Includes report count if reports exist
- [ ] Includes seller response if exists
- [ ] Results sorted by createdAt descending by default
