# REV-012: Admin Hide Review

## User Story
As an admin, I want to hide inappropriate reviews, so that I can remove content that violates guidelines while preserving the review data for records.

## API

**Endpoint:** `PUT /api/v1/admin/reviews/{reviewId}/hide`

**Path Parameters:**
- `reviewId` (string, required): The review identifier

**Request Body:**
```json
{
  "reason": "INAPPROPRIATE_CONTENT",
  "notes": "Review contains offensive language."
}
```

**Reason Options:**
- `INAPPROPRIATE_CONTENT` - Contains inappropriate language or content
- `FAKE_REVIEW` - Confirmed fake or incentivized review
- `PROMOTIONAL` - Contains promotional material
- `COMPETITOR_PROMOTION` - Promotes competitor products
- `SPAM` - Spam or bot-generated content
- `OTHER` - Other violation (notes required)

**Response (200 OK):**
```json
{
  "id": "rev-001",
  "status": "HIDDEN",
  "hiddenReason": "INAPPROPRIATE_CONTENT",
  "hiddenAt": "2026-04-04T13:00:00Z",
  "hiddenBy": "admin-001"
}
```

## Acceptance Criteria

- [ ] User must have ADMIN role
- [ ] Returns 404 if review does not exist
- [ ] Returns 400 if reason is OTHER and notes are empty
- [ ] Review status changes to HIDDEN
- [ ] Hidden reviews are not visible to regular users
- [ ] Hidden reviews are still visible in admin views with status indicator
- [ ] All seller responses are also hidden
- [ ] Action is logged with admin ID, reason, and notes
