# REV-013: Admin Delete Review

## User Story
As an admin, I want to permanently delete reviews that violate policies, so that I can completely remove content that is severely inappropriate or fraudulent.

## API

**Endpoint:** `DELETE /api/v1/admin/reviews/{reviewId}`

**Path Parameters:**
- `reviewId` (string, required): The review identifier

**Request Body:**
```json
{
  "reason": "FAKE_REVIEW",
  "notes": "Confirmed through investigation that this review was incentivized."
}
```

**Reason Options:**
- `FAKE_REVIEW` - Confirmed fake or incentivized review
- `SEVERE_VIOLATION` - Severe policy violation
- `LEGAL_REQUIREMENT` - Required by legal/compliance
- `USER_REQUEST` - User request with verification
- `OTHER` - Other reason (notes required)

**Response (200 OK):**
```json
{
  "id": "rev-001",
  "status": "DELETED",
  "deletedReason": "FAKE_REVIEW",
  "deletedAt": "2026-04-04T14:00:00Z",
  "deletedBy": "admin-001"
}
```

## Acceptance Criteria

- [ ] User must have ADMIN role
- [ ] Returns 404 if review does not exist
- [ ] Returns 400 if reason is OTHER and notes are empty
- [ ] Review is soft deleted (marked as DELETED status)
- [ ] Deleted reviews are not visible to any users except admins
- [ ] Seller response is also deleted
- [ ] All votes and reports are retained for audit
- [ ] Action is logged with admin ID, reason, and notes
- [ ] Returns 200 on successful deletion
