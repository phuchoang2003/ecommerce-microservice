# PRO-001: Create Coupon

## User Story
As a platform administrator, I want to create platform-wide coupons so that customers can receive discounts on their orders.

## API
```
POST /api/v1/promotions/coupons
```

### Request Body
```json
{
  "code": "SUMMER2024",
  "description": "Summer sale discount",
  "discountType": "PERCENTAGE",
  "discountValue": 15.0,
  "minOrderAmount": 50.0,
  "maxDiscountAmount": 100.0,
  "startDate": "2024-06-01T00:00:00Z",
  "endDate": "2024-08-31T23:59:59Z",
  "usageLimit": 1000,
  "perUserLimit": 1,
  "applicableCategories": [],
  "applicableProducts": []
}
```

### Response (201 Created)
```json
{
  "id": "coupon-123",
  "code": "SUMMER2024",
  "description": "Summer sale discount",
  "discountType": "PERCENTAGE",
  "discountValue": 15.0,
  "minOrderAmount": 50.0,
  "maxDiscountAmount": 100.0,
  "startDate": "2024-06-01T00:00:00Z",
  "endDate": "2024-08-31T23:59:59Z",
  "usageLimit": 1000,
  "usageCount": 0,
  "perUserLimit": 1,
  "applicableCategories": [],
  "applicableProducts": [],
  "status": "ACTIVE",
  "createdAt": "2024-05-15T10:30:00Z",
  "updatedAt": "2024-05-15T10:30:00Z"
}
```

## Acceptance Criteria
- [ ] Coupon code must be unique across the platform
- [ ] Discount type must be either PERCENTAGE or FIXED_AMOUNT
- [ ] Discount value must be positive
- [ ] End date must be after start date
- [ ] Usage limit must be greater than 0
- [ ] Per user limit must be at least 1
- [ ] Returns 409 Conflict if coupon code already exists
- [ ] Returns 400 Bad Request for invalid input
