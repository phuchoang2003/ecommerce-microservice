# PRO-002: List Coupons

## User Story
As a platform administrator, I want to list all coupons so that I can manage and monitor coupon usage.

## API
```
GET /api/v1/promotions/coupons
```

### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| page | int | No | Page number (default: 0) |
| size | int | No | Page size (default: 20, max: 100) |
| status | string | No | Filter by status (ACTIVE, INACTIVE, EXPIRED) |
| discountType | string | No | Filter by discount type |
| startDate | datetime | No | Filter by start date range |
| endDate | datetime | No | Filter by end date range |

### Response (200 OK)

{
  "content": [
    {
      "id": "coupon-123",
      "code": "SUMMER2024",
      "description": "Summer sale discount",
      "discountType": "PERCENTAGE",
      "discountValue": 15.0,
      "minOrderAmount": 50.0,
      "maxDiscountAmount": 100.0,
      "startDate": "2024-06-01T00:00:00Z",
      "endDate": "2024-08-31T23:59:59Z",
      "usageLimit": 1000,
      "usageCount": 150,
      "perUserLimit": 1,
      "status": "ACTIVE",
      "createdAt": "2024-05-15T10:30:00Z"
    }

## Acceptance Criteria
- [ ] Returns paginated list of coupons
- [ ] Supports filtering by status
- [ ] Supports filtering by discount type
- [ ] Supports filtering by date range
- [ ] Results are ordered by creation date descending
- [ ] Returns empty list when no coupons match criteria
