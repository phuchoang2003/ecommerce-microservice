# PRO-003: Update Coupon

## User Story
As a platform administrator, I want to update coupon details so that I can adjust promotions as needed.

## API
```
PUT /api/v1/promotions/coupons/{couponId}
```

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| couponId | string | Yes | Unique coupon identifier |

### Request Body
```json
{
  "description": "Updated summer sale discount",
  "discountValue": 20.0,
  "minOrderAmount": 75.0,
  "maxDiscountAmount": 150.0,
  "endDate": "2024-09-30T23:59:59Z",
  "usageLimit": 2000,
  "perUserLimit": 2
}
```

### Response (200 OK)
```json
{
  "id": "coupon-123",
  "code": "SUMMER2024",
  "description": "Updated summer sale discount",
  "discountType": "PERCENTAGE",
  "discountValue": 20.0,
  "minOrderAmount": 75.0,
  "maxDiscountAmount": 150.0,
  "startDate": "2024-06-01T00:00:00Z",
  "endDate": "2024-09-30T23:59:59Z",
  "usageLimit": 2000,
  "usageCount": 150,
  "perUserLimit": 2,
  "status": "ACTIVE",
  "createdAt": "2024-05-15T10:30:00Z",
  "updatedAt": "2024-05-20T14:00:00Z"
}
```

## Acceptance Criteria
- [ ] Cannot update coupon code
- [ ] Cannot update discount type
- [ ] Cannot decrease usage limit below current usage count
- [ ] Cannot set end date before current date
- [ ] Returns 404 Not Found if coupon does not exist
- [ ] Returns 400 Bad Request for invalid input
- [ ] Only specified fields are updated
