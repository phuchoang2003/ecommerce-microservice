# PRO-004: Deactivate Coupon

## User Story
As a platform administrator, I want to deactivate coupons so that I can stop promotions early if needed.

## API
```
PUT /api/v1/promotions/coupons/{couponId}/deactivate
```

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| couponId | string | Yes | Unique coupon identifier |

### Response (200 OK)
```json
{
  "id": "coupon-123",
  "code": "SUMMER2024",
  "description": "Summer sale discount",
  "discountType": "PERCENTAGE",
  "discountValue": 15.0,
  "status": "INACTIVE",
  "createdAt": "2024-05-15T10:30:00Z",
  "updatedAt": "2024-05-20T15:00:00Z",
  "deactivatedAt": "2024-05-20T15:00:00Z"
}
```

## Acceptance Criteria
- [ ] Sets coupon status to INACTIVE
- [ ] Records deactivation timestamp
- [ ] Deactivated coupons cannot be applied to new orders
- [ ] Previously applied coupons remain valid for existing orders
- [ ] Returns 404 Not Found if coupon does not exist
- [ ] Returns 400 Bad Request if coupon is already inactive
