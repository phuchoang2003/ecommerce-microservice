# PRO-005: Validate Coupon

## User Story
As a customer, I want to validate a coupon code before checkout so that I know if it is valid and what discount I will receive.

## API
```
POST /api/v1/promotions/coupons/validate
```

### Request Body
```json
{
  "code": "SUMMER2024",
  "orderAmount": 100.0,
  "userId": "user-456",
  "categoryIds": ["cat-1", "cat-2"],
  "productIds": ["prod-100", "prod-101"]
}
```

### Response (200 OK)
```json
{
  "valid": true,
  "couponId": "coupon-123",
  "code": "SUMMER2024",
  "discountType": "PERCENTAGE",
  "discountValue": 15.0,
  "calculatedDiscount": 15.0,
  "msg": "Coupon is valid"
}
```

### Response (200 OK - Invalid Coupon)
```json
{
  "valid": false,
  "code": "SUMMER2024",
  "msg": "Coupon has expired"
}
```

## Acceptance Criteria
- [ ] Validates coupon exists and is active
- [ ] Validates coupon is within valid date range
- [ ] Validates order meets minimum amount requirement
- [ ] Validates user has not exceeded per-user limit
- [ ] Validates coupon has remaining usage
- [ ] Validates applicable categories and products
- [ ] Returns calculated discount amount
- [ ] Returns detailed error msg for invalid coupons
