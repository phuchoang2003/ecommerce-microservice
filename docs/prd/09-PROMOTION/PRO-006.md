# PRO-006: Apply Coupon

## User Story
As a customer, I want to apply a coupon to my order so that I can receive the discount.

## API
```
POST /api/v1/promotions/coupons/apply
```

### Request Body
```json
{
  "code": "SUMMER2024",
  "orderId": "order-789",
  "userId": "user-456"
}
```

### Response (200 OK)
```json
{
  "orderId": "order-789",
  "couponId": "coupon-123",
  "code": "SUMMER2024",
  "discountType": "PERCENTAGE",
  "discountValue": 15.0,
  "discountAmount": 15.0,
  "originalTotal": 100.0,
  "finalTotal": 85.0,
  "appliedAt": "2024-06-15T11:00:00Z"
}
```

## Acceptance Criteria
- [ ] Validates coupon before applying
- [ ] Creates coupon usage record
- [ ] Updates coupon usage count
- [ ] Calculates correct discount amount
- [ ] Records discount in order
- [ ] Returns 400 Bad Request if coupon is invalid
- [ ] Returns 404 Not Found if order does not exist
- [ ] Returns 409 Conflict if coupon already applied to order
- [ ] Idempotent - applying same coupon twice returns existing result
