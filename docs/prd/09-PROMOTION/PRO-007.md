# PRO-007: Create Flash Sale

## User Story
As a platform administrator, I want to create flash sales so that customers can participate in time-limited promotional events.

## API
```
POST /api/v1/promotions/flash-sales
```

### Request Body
```json
{
  "name": "Summer Flash Sale",
  "description": "24-hour summer sale event",
  "startTime": "2024-06-21T00:00:00Z",
  "endTime": "2024-06-22T00:00:00Z",
  "maxOrdersPerUser": 3,
  "bannerUrl": "https://example.com/banner.jpg"
}
```

### Response (201 Created)
```json
{
  "id": "flash-sale-123",
  "name": "Summer Flash Sale",
  "description": "24-hour summer sale event",
  "startTime": "2024-06-21T00:00:00Z",
  "endTime": "2024-06-22T00:00:00Z",
  "maxOrdersPerUser": 3,
  "bannerUrl": "https://example.com/banner.jpg",
  "status": "SCHEDULED",
  "productCount": 0,
  "createdAt": "2024-05-20T10:00:00Z",
  "updatedAt": "2024-05-20T10:00:00Z"
}
```

## Acceptance Criteria
- [ ] Flash sale start time must be in the future
- [ ] End time must be after start time
- [ ] Duration must be at least 1 hour
- [ ] Duration must not exceed 7 days
- [ ] Max orders per user must be at least 1
- [ ] Status defaults to SCHEDULED
- [ ] Returns 400 Bad Request for invalid input
