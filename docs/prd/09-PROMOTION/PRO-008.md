# PRO-008: Add Flash Sale Product

## User Story
As a platform administrator, I want to add products to a flash sale so that customers can purchase them at discounted prices.

## API
```
POST /api/v1/promotions/flash-sales/{id}/products
```

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| id | string | Yes | Flash sale identifier |

### Request Body
```json
{
  "products": [
    {
      "productId": "prod-100",
      "originalPrice": 99.99,
      "flashSalePrice": 79.99,
      "stockQuantity": 500
    },
    {
      "productId": "prod-101",
      "originalPrice": 149.99,
      "flashSalePrice": 119.99,
      "stockQuantity": 300
    }
  ]
}
```

### Response (201 Created)
```json
{
  "flashSaleId": "flash-sale-123",
  "addedProducts": [
    {
      "productId": "prod-100",
      "name": "Product Name",
      "originalPrice": 99.99,
      "flashSalePrice": 79.99,
      "discountPercentage": 20.01,
      "stockQuantity": 500,
      "soldQuantity": 0
    },
    {
      "productId": "prod-101",
      "name": "Product Name 2",
      "originalPrice": 149.99,
      "flashSalePrice": 119.99,
      "discountPercentage": 20.0,
      "stockQuantity": 300,
      "soldQuantity": 0
    }
  ],
  "totalProducts": 2
}
```

## Acceptance Criteria
- [ ] Flash sale price must be lower than original price
- [ ] Discount percentage must be at least 5%
- [ ] Stock quantity must be positive
- [ ] Cannot add products to ended flash sale
- [ ] Cannot add duplicate products to same flash sale
- [ ] Returns 404 Not Found if flash sale does not exist
- [ ] Returns 400 Bad Request if flash sale has started
- [ ] Returns 409 Conflict if product already in flash sale
