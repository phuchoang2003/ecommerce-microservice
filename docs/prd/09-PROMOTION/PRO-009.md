# PRO-009: Start Flash Sale

## User Story
As a platform administrator, I want to start a flash sale so that customers can begin purchasing discounted products.

## API
```
PUT /api/v1/promotions/flash-sales/{id}/start
```

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| id | string | Yes | Flash sale identifier |

### Response (200 OK)
```json
{
  "id": "flash-sale-123",
  "name": "Summer Flash Sale",
  "description": "24-hour summer sale event",
  "startTime": "2024-06-21T00:00:00Z",
  "endTime": "2024-06-22T00:00:00Z",
  "status": "ACTIVE",
  "productCount": 15,
  "startedAt": "2024-06-21T00:00:00Z",
  "updatedAt": "2024-06-21T00:00:00Z"
}
```

## Acceptance Criteria
- [ ] Flash sale must be in SCHEDULED status
- [ ] Current time must be at or after start time
- [ ] Flash sale must have at least one product
- [ ] Sets status to ACTIVE
- [ ] Records actual start timestamp
- [ ] Returns 404 Not Found if flash sale does not exist
- [ ] Returns 400 Bad Request if flash sale is not scheduled
- [ ] Returns 400 Bad Request if flash sale has not started yet
- [ ] Returns 400 Bad Request if flash sale has no products
