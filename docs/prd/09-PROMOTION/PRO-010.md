# PRO-010: End Flash Sale

## User Story
As a platform administrator, I want to end a flash sale so that customers can no longer purchase products at discounted prices.

## API
```
PUT /api/v1/promotions/flash-sales/{id}/end
```

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| id | string | Yes | Flash sale identifier |

### Response (200 OK)
```json
{
  "id": "flash-sale-123",
  "name": "Summer Flash Sale",
  "description": "24-hour summer sale event",
  "startTime": "2024-06-21T00:00:00Z",
  "endTime": "2024-06-22T00:00:00Z",
  "status": "ENDED",
  "productCount": 15,
  "totalOrders": 1250,
  "totalRevenue": 87500.00,
  "endedAt": "2024-06-22T00:00:00Z",
  "updatedAt": "2024-06-22T00:00:00Z"
}
```

## Acceptance Criteria
- [ ] Flash sale must be in ACTIVE status
- [ ] Sets status to ENDED
- [ ] Records actual end timestamp
- [ ] Calculates total orders and revenue
- [ ] Returns 404 Not Found if flash sale does not exist
- [ ] Returns 400 Bad Request if flash sale is not active
- [ ] Prevents new orders from using flash sale prices
- [ ] Existing pending orders remain valid
