# PRO-011: Create Bundle Deal

## User Story
As a platform administrator, I want to create bundle deals so that customers can receive discounts when purchasing product bundles.

## API
```
POST /api/v1/promotions/bundles
```

### Request Body
```json
{
  "name": "Electronics Bundle",
  "description": "Buy laptop, tablet, and headphones together",
  "productIds": ["prod-100", "prod-200", "prod-300"],
  "bundlePrice": 1299.99,
  "startDate": "2024-07-01T00:00:00Z",
  "endDate": "2024-07-31T23:59:59Z",
  "maxRedemptions": 500,
  "minQuantityPerProduct": 1
}
```

### Response (201 Created)
```json
{
  "id": "bundle-123",
  "name": "Electronics Bundle",
  "description": "Buy laptop, tablet, and headphones together",
  "products": [
    {
      "productId": "prod-100",
      "name": "Laptop",
      "price": 999.99
    },
    {
      "productId": "prod-200",
      "name": "Tablet",
      "price": 399.99
    },
    {
      "productId": "prod-300",
      "name": "Headphones",
      "price": 149.99
    }
  ],
  "totalPrice": 1549.97,
  "bundlePrice": 1299.99,
  "discountAmount": 249.98,
  "discountPercentage": 16.13,
  "startDate": "2024-07-01T00:00:00Z",
  "endDate": "2024-07-31T23:59:59Z",
  "maxRedemptions": 500,
  "redemptionCount": 0,
  "status": "ACTIVE",
  "createdAt": "2024-06-01T10:00:00Z"
}
```

## Acceptance Criteria
- [ ] Bundle must contain at least 2 products
- [ ] Bundle price must be lower than sum of individual product prices
- [ ] Products must exist and be active
- [ ] End date must be after start date
- [ ] Max redemptions must be positive
- [ ] Min quantity per product must be at least 1
- [ ] Returns 400 Bad Request for invalid input
- [ ] Returns 404 Not Found if any product does not exist
