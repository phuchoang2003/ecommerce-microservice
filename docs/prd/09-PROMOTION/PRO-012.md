# PRO-012: Validate Bundle

## User Story
As a customer, I want to validate a bundle deal before purchasing so that I know if it is valid and the discount I will receive.

## API
```
POST /api/v1/promotions/bundles/validate
```

### Request Body
```json
{
  "bundleId": "bundle-123",
  "userId": "user-456",
  "quantities": {
    "prod-100": 1,
    "prod-200": 1,
    "prod-300": 1
  }
}
```

### Response (200 OK)
```json
{
  "valid": true,
  "bundleId": "bundle-123",
  "name": "Electronics Bundle",
  "bundlePrice": 1299.99,
  "individualTotal": 1549.97,
  "discountAmount": 249.98,
  "discountPercentage": 16.13,
  "msg": "Bundle is valid"
}
```

### Response (200 OK - Invalid Bundle)
```json
{
  "valid": false,
  "bundleId": "bundle-123",
  "msg": "Bundle deal has ended"
}
```

## Acceptance Criteria
- [ ] Validates bundle exists and is active
- [ ] Validates bundle is within valid date range
- [ ] Validates all products in bundle are available
- [ ] Validates stock availability for requested quantities
- [ ] Validates user has not exceeded max redemptions
- [ ] Returns calculated discount details
- [ ] Returns detailed error msg for invalid bundles
