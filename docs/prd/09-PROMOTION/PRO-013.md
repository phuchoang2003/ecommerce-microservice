# PRO-013: Apply Bundle

## User Story
As a customer, I want to apply a bundle deal to my order so that I can receive the bundle discount.

## API
```
POST /api/v1/promotions/bundles/apply
```

### Request Body
```json
{
  "bundleId": "bundle-123",
  "orderId": "order-789",
  "userId": "user-456",
  "quantities": {
    "prod-100": 1,
    "prod-200": 1,
    "prod-300": 1
  }
}
```

### Response (200 OK)
```json
{
  "orderId": "order-789",
  "bundleId": "bundle-123",
  "name": "Electronics Bundle",
  "appliedProducts": [
    {
      "productId": "prod-100",
      "name": "Laptop",
      "quantity": 1,
      "originalPrice": 999.99,
      "bundlePrice": 839.99
    },
    {
      "productId": "prod-200",
      "name": "Tablet",
      "quantity": 1,
      "originalPrice": 399.99,
      "bundlePrice": 339.99
    },
    {
      "productId": "prod-300",
      "name": "Headphones",
      "quantity": 1,
      "originalPrice": 149.99,
      "bundlePrice": 120.01
    }
  ],

  "bundleTotal": 1299.99,

```

## Acceptance Criteria
- [ ] Validates bundle before applying
- [ ] Creates bundle redemption record
- [ ] Updates bundle redemption count
- [ ] Applies bundle prices to order items
- [ ] Calculates correct discount amount
- [ ] Records discount in order
- [ ] Returns 400 Bad Request if bundle is invalid
- [ ] Returns 404 Not Found if order does not exist
- [ ] Returns 409 Conflict if bundle already applied to order
- [ ] Idempotent - applying same bundle twice returns existing result
