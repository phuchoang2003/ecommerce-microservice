# PRO-014: Free Shipping Promo

## User Story
As a platform administrator, I want to create free shipping promotions so that customers can receive free shipping on their orders.

## API
```
POST /api/v1/promotions/free-shipping
```

### Request Body
```json
{
  "name": "Free Shipping Summer Promo",
  "description": "Free shipping on all orders over $50",
  "minimumOrderAmount": 50.0,
  "shippingMethods": ["STANDARD", "EXPRESS"],
  "region": "ALL",
  "startDate": "2024-06-01T00:00:00Z",
  "endDate": "2024-08-31T23:59:59Z",
  "maxBeneficiaries": 10000,
  "couponCode": "FREESHIP50"
}
```

### Response (201 Created)
```json
{
  "id": "free-ship-123",
  "name": "Free Shipping Summer Promo",
  "description": "Free shipping on all orders over $50",
  "minimumOrderAmount": 50.0,
  "shippingMethods": ["STANDARD", "EXPRESS"],
  "region": "ALL",
  "startDate": "2024-06-01T00:00:00Z",
  "endDate": "2024-08-31T23:59:59Z",
  "maxBeneficiaries": 10000,
  "beneficiaryCount": 0,
  "couponCode": "FREESHIP50",
  "status": "ACTIVE",
  "createdAt": "2024-05-15T10:00:00Z"
}
```

## Acceptance Criteria
- [ ] Minimum order amount must be non-negative
- [ ] Shipping methods must include at least one valid method
- [ ] Region must be valid region code or ALL
- [ ] End date must be after start date
- [ ] Max beneficiaries must be positive if specified
- [ ] Coupon code is optional and must be unique if provided
- [ ] Returns 400 Bad Request for invalid input
