# PRO-015: Calculate Shipping

## User Story
As a customer, I want to calculate shipping costs with promotions applied so that I can see the final shipping cost before placing my order.

## API
```
GET /api/v1/promotions/free-shipping/calculate
```

### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| userId | string | Yes | User identifier |
| orderAmount | decimal | Yes | Order subtotal |
| shippingMethod | string | Yes | Shipping method (STANDARD, EXPRESS, OVERNIGHT) |
| region | string | Yes | Delivery region code |

### Response (200 OK - With Free Shipping)
```json
{
  "eligible": true,
  "originalShippingCost": 9.99,
  "discountedShippingCost": 0.0,
  "promotionId": "free-ship-123",
  "promotionName": "Free Shipping Summer Promo",
  "msg": "Free shipping applied!"
}
```

### Response (200 OK - Without Free Shipping)
```json
{
  "eligible": false,
  "originalShippingCost": 9.99,
  "discountedShippingCost": 9.99,
  "promotionId": null,
  "promotionName": null,
  "msg": "Order amount does not meet minimum of $50.00",
  "minimumRequired": 50.0,
  "shortfall": 15.0
}
```

## Acceptance Criteria
- [ ] Validates user exists
- [ ] Checks all active free shipping promotions
- [ ] Validates order meets minimum amount requirement
- [ ] Validates shipping method is covered by promotion
- [ ] Validates region is covered by promotion
- [ ] Returns correct shipping cost with discount applied
- [ ] Returns detailed msg explaining eligibility
- [ ] Returns remaining amount needed if not eligible
- [ ] Returns regular shipping cost if no promotion applies
