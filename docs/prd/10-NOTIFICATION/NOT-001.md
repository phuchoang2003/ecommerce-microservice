# NOT-001: Register Device

## User Story

**As a** mobile application user
**I want to** register my device for push notifications
**So that** I can receive push notifications on my device

## API Specification

### POST /api/v1/notifications/devices

**Description:** Register a device to receive push notifications.

**Headers:**
- `Content-Type: application/json`
- `X-User-Id: string` (required)

**Request Body:**
```json
{
  "deviceToken": "string",
  "platform": "IOS | ANDROID | WEB",
  "deviceName": "string",
  "deviceModel": "string"
}
```

**Response (201 Created):**
```json
{
  "id": "uuid",
  "userId": "string",
  "deviceToken": "string",
  "platform": "IOS",
  "deviceName": "iPhone 15",
  "deviceModel": "Apple A3092",
  "createdAt": "2026-04-04T10:00:00Z",
  "updatedAt": "2026-04-04T10:00:00Z"
}
```

**Error Responses:**
- `400 Bad Request` - Invalid request body
- `401 Unauthorized` - Missing or invalid user ID
- `409 Conflict` - Device already registered

## Acceptance Criteria

- [ ] Device can be registered with a valid device token
- [ ] Device token is stored securely
- [ ] Duplicate device registration returns 409 Conflict
- [ ] Platform must be IOS, ANDROID, or WEB
- [ ] Registration returns device ID and timestamp
- [ ] User can register multiple devices
