# NOT-002: List Devices

## User Story

**As a** mobile application user
**I want to** view all my registered devices
**So that** I can manage which devices receive push notifications

## API Specification

### GET /api/v1/notifications/devices

**Description:** List all devices registered for the authenticated user.

**Headers:**
- `X-User-Id: string` (required)

**Response (200 OK):**
```json
{
  "devices": [
    {
      "id": "uuid",
      "userId": "string",
      "deviceToken": "string",
      "platform": "IOS",
      "deviceName": "iPhone 15",
      "deviceModel": "Apple A3092",
      "createdAt": "2026-04-04T10:00:00Z",
      "updatedAt": "2026-04-04T10:00:00Z"
    }
  ],
  "total": 1
}
```

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID

## Acceptance Criteria

- [ ] Returns all devices for the authenticated user
- [ ] Response includes device ID, name, platform, and model
- [ ] Empty list returned if no devices registered
- [ ] Device tokens are masked in response (show only last 4 chars)
