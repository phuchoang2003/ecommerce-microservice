# NOT-003: Delete Device

## User Story

**As a** mobile application user
**I want to** unregister a device from push notifications
**So that** I can stop receiving notifications on devices I no longer use

## API Specification

### DELETE /api/v1/notifications/devices/{deviceId}

**Description:** Delete a registered device.

**Headers:**
- `X-User-Id: string` (required)

**Path Parameters:**
- `deviceId: uuid` (required) - The ID of the device to delete

**Response (204 No Content)**

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID
- `404 Not Found` - Device not found or does not belong to user

## Acceptance Criteria

- [ ] Device is removed from the system
- [ ] User can only delete their own devices
- [ ] Returns 204 on successful deletion
- [ ] Returns 404 if device does not exist or belongs to another user
- [ ] Push notifications stop immediately for deleted device
