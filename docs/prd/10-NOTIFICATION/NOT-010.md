# NOT-010: Get Notifications

## User Story

**As a** mobile application user
**I want to** retrieve my notifications
**So that** I can view my notification history

## API Specification

### GET /api/v1/notifications

**Description:** Get paginated list of notifications for the authenticated user.

**Headers:**
- `X-User-Id: string` (required)

**Query Parameters:**
- `page: integer` (optional, default: 0)
- `size: integer` (optional, default: 20, max: 100)
- `sort: string` (optional, default: "createdAt,desc")

**Response (200 OK):**
```json
{
  "notifications": [
    {
      "id": "uuid",
      "userId": "string",
      "title": "Order Shipped",
      "body": "Your order #12345 has been shipped",
      "type": "ORDER_UPDATE",
      "read": false,
      "data": {
        "orderId": "12345"
      },
      "createdAt": "2026-04-04T10:00:00Z"
    }
  ],
  "page": 0,
  "size": 20,
  "totalElements": 1,
  "totalPages": 1
}
```

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID

## Acceptance Criteria

- [ ] Returns paginated notifications
- [ ] Notifications sorted by creation date (newest first) by default
- [ ] Each notification includes read status
- [ ] Supports filtering by page and size
- [ ] Response includes total count for pagination
