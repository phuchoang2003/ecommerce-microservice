# NOT-011: Mark Read

## User Story

**As a** mobile application user
**I want to** mark a notification as read
**So that** I can track which notifications I have already viewed

## API Specification

### PUT /api/v1/notifications/{notificationId}/read

**Description:** Mark a single notification as read.

**Headers:**
- `X-User-Id: string` (required)

**Path Parameters:**
- `notificationId: uuid` (required) - The ID of the notification to mark as read

**Response (200 OK):**
```json
{
  "id": "uuid",
  "userId": "string",
  "title": "Order Shipped",
  "body": "Your order #12345 has been shipped",
  "type": "ORDER_UPDATE",
  "read": true,
  "data": {
    "orderId": "12345"
  },
  "createdAt": "2026-04-04T10:00:00Z"
}
```

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID
- `404 Not Found` - Notification not found or does not belong to user

## Acceptance Criteria

- [ ] Notification is marked as read
- [ ] User can only mark their own notifications as read
- [ ] Already-read notifications remain unchanged
- [ ] Returns updated notification with read=true
- [ ] Returns 404 if notification does not exist or belongs to another user
