# NOT-012: Mark All Read

## User Story

**As a** mobile application user
**I want to** mark all my notifications as read
**So that** I can quickly clear my unread notification count

## API Specification

### PUT /api/v1/notifications/read-all

**Description:** Mark all notifications as read for the authenticated user.

**Headers:**
- `X-User-Id: string` (required)

**Response (200 OK):**
```json
{
  "markedCount": 15,
  "msg": "All notifications marked as read"
}
```

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID

## Acceptance Criteria

- [ ] All unread notifications are marked as read
- [ ] Returns count of notifications marked
- [ ] Already-read notifications remain unchanged
- [ ] Operation is atomic (all or nothing)
