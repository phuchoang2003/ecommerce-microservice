# NOT-013: Delete Notification

## User Story

**As a** mobile application user
**I want to** delete a notification
**So that** I can remove notifications I no longer need

## API Specification

### DELETE /api/v1/notifications/{notificationId}

**Description:** Delete a notification.

**Headers:**
- `X-User-Id: string` (required)

**Path Parameters:**
- `notificationId: uuid` (required) - The ID of the notification to delete

**Response (204 No Content)**

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID
- `404 Not Found` - Notification not found or does not belong to user

## Acceptance Criteria

- [ ] Notification is permanently deleted
- [ ] User can only delete their own notifications
- [ ] Returns 204 on successful deletion
- [ ] Returns 404 if notification does not exist or belongs to another user
- [ ] Deletion is irreversible
