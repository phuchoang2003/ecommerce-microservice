# NOT-014: Get Unread Count

## User Story

**As a** mobile application user
**I want to** see the count of unread notifications
**So that** I can quickly know how many new notifications I have

## API Specification

### GET /api/v1/notifications/unread-count

**Description:** Get the count of unread notifications for the authenticated user.

**Headers:**
- `X-User-Id: string` (required)

**Response (200 OK):**
```json
{
  "unreadCount": 5
}
```

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID

## Acceptance Criteria

- [ ] Returns accurate count of unread notifications
- [ ] Count is a non-negative integer
- [ ] Response time is fast (optimized query)
- [ ] Count updates immediately when notifications are read or deleted
