# NOT-015: Update Preferences

## User Story

**As a** mobile application user
**I want to** update my notification preferences
**So that** I can control what types of notifications I receive

## API Specification

### PUT /api/v1/notifications/preferences

**Description:** Update notification preferences for the authenticated user.

**Headers:**
- `Content-Type: application/json`
- `X-User-Id: string` (required)

**Request Body:**
```json
{
  "orderUpdates": true,
  "promotions": true,
  "securityAlerts": true,
  "marketing": false,
  "emailEnabled": true,
  "pushEnabled": true,
  "quietHoursStart": "22:00",
  "quietHoursEnd": "08:00"
}
```

**Response (200 OK):**
```json
{
  "orderUpdates": true,
  "promotions": true,
  "securityAlerts": true,
  "marketing": false,
  "emailEnabled": true,
  "pushEnabled": true,
  "quietHoursStart": "22:00",
  "quietHoursEnd": "08:00",
  "updatedAt": "2026-04-04T10:00:00Z"
}
```

**Error Responses:**
- `400 Bad Request` - Invalid preference values
- `401 Unauthorized` - Missing or invalid user ID

## Acceptance Criteria

- [ ] Preferences are saved and persisted
- [ ] Invalid preference values return 400 error
- [ ] Only specified preferences are updated
- [ ] Returns full preferences object after update
- [ ] Quiet hours must be valid time format (HH:mm)
- [ ] Start time must be before end time
