# NOT-016: Get Preferences

## User Story

**As a** mobile application user
**I want to** view my notification preferences
**So that** I can see what notification settings are currently active

## API Specification

### GET /api/v1/notifications/preferences

**Description:** Get notification preferences for the authenticated user.

**Headers:**
- `X-User-Id: string` (required)

**Response (200 OK):**
```json
{
  "orderUpdates": true,
  "promotions": true,
  "securityAlerts": true,
  "marketing": false,
  "emailEnabled": true,
  "pushEnabled": true,
  "quietHoursStart": "22:00",
  "quietHoursEnd": "08:00",
  "updatedAt": "2026-04-04T10:00:00Z"
}
```

**Error Responses:**
- `401 Unauthorized` - Missing or invalid user ID

## Acceptance Criteria

- [ ] Returns all notification preferences for the user
- [ ] Default preferences applied for new users
- [ ] All preference fields are included in response
- [ ] Returns 401 if user is not authenticated
