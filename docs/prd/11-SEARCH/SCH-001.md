# SCH-001 - Search Products

## User Story

**As a** customer
**I want to** search for products by keyword
**So that** I can find items I want to purchase

## API

### GET /api/v1/search

Search for products using full-text search with optional filters.

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| q | string | Yes | Search query keyword |
| filters | string | No | JSON-encoded filter object |
| sort | string | No | Sort option: relevance, price_asc, price_desc, sales_count, rating, newest |
| page | integer | No | Page number (default: 0) |
| size | integer | No | Page size (default: 20, max: 100) |

**Filter Object Structure:**
```json
{
  "categoryId": "string",
  "categoryPath": ["electronics", "phones"],
  "priceMin": 100,
  "priceMax": 1000,
  "ratingMin": 4,
  "location": "Jakarta",
  "freeShipping": true,
  "variants": ["128GB", "256GB"]
}
```

**Request Example:**
```http
GET /api/v1/search?q=iphone&filters={"priceMin":500,"ratingMin":4}&sort=relevance&page=0&size=20
```

## Acceptance Criteria

- [ ] Search returns products matching the query keyword
- [ ] Results are sorted by relevance by default
- [ ] Filters correctly narrow down results
- [ ] Pagination works correctly with page and size parameters
- [ ] Response includes facet counts for categories, price ranges, locations, and ratings
- [ ] Empty query returns appropriate error msg
- [ ] Search highlights matching terms in results
