# SCH-002 - Search Suggestions

## User Story

**As a** customer
**I want to** get search suggestions as I type
**So that** I can quickly find what I am looking for

## API

### GET /api/v1/search/suggestions

Get autocomplete suggestions based on partial query input.

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| q | string | Yes | Partial search query |
| limit | integer | No | Maximum suggestions to return (default: 10, max: 20) |

**Request Example:**
```http
GET /api/v1/search/suggestions?q=iph&limit=10
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "data": {
    "suggestions": [
      {
        "productId": "P001",
        "name": "iPhone 15 Pro Max",
        "image": "https://example.com/iphone15.jpg",
        "price": 15990000,
        "relevanceScore": 0.95
      },
      {
        "productId": "P002",
        "name": "iPhone 14 Pro",
        "image": "https://example.com/iphone14.jpg",
        "price": 13990000,
        "relevanceScore": 0.88
      },
      {
        "productId": "P003",
        "name": "iPhone Case",
        "image": "https://example.com/case.jpg",
        "price": 150000,
        "relevanceScore": 0.75
      }
    ]
  }
}
```

**Error Response (400 Bad Request):**
```json
{
  "success": false,
  "error": {
    "code": "INVALID_QUERY",
    "msg": "Query parameter 'q' is required"
  }
}
```

## Acceptance Criteria

- [ ] Suggestions are returned within 100ms response time
- [ ] Maximum 10 suggestions returned by default
- [ ] Results are ordered by relevance score
- [ ] Each suggestion includes productId, name, image, and price
- [ ] Prefix matching works correctly
- [ ] Empty query returns empty suggestions array
- [ ] Special characters in query are handled properly
