# SCH-003 - Get Filters

## User Story

**As a** customer
**I want to** see available filter options for a search
**So that** I can narrow down my product search

## API

### GET /api/v1/search/filters

Get available filter options and their counts for the current search context.

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| q | string | No | Search query to get filters for |
| categoryId | string | No | Category ID to get filters within |

**Request Example:**
```http
GET /api/v1/search/filters?q=phone&categoryId=CAT001
```

## Acceptance Criteria

- [ ] Returns all filter categories with hierarchical structure
- [ ] Each filter option includes accurate count
- [ ] Price ranges are properly segmented
- [ ] Location filters show seller locations with product counts
- [ ] Rating filters show minimum rating thresholds
- [ ] Variant filters show available options like storage sizes
- [ ] Counts reflect products matching the current search query
