# SCH-004 - Get Trending

## User Story

**As a** customer
**I want to** see trending search terms
**So that** I can discover popular products and trends

## API

### GET /api/v1/search/trending

Get currently trending search terms.

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| limit | integer | No | Number of trending terms to return (default: 10, max: 50) |

**Request Example:**
```http
GET /api/v1/search/trending?limit=10
```

## Acceptance Criteria

- [ ] Returns trending search terms sorted by search count
- [ ] Each term includes rank, term, and search count
- [ ] Trend indicator shows rising, stable, falling, or new
- [ ] Results update periodically (at least hourly)
- [ ] Maximum 50 terms can be returned
- [ ] Empty result returns empty array when no trending data
