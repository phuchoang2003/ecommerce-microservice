# SCH-005 - Get Recent Searches

## User Story

**As a** customer
**I want to** see my recent search history
**So that** I can quickly search for items I previously looked for

## API

### GET /api/v1/search/recent

Get recent search history for the current user.

**Headers:**

| Header | Type | Required | Description |
|--------|------|----------|-------------|
| X-User-Id | string | Yes | Authenticated user ID |

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| limit | integer | No | Number of recent searches to return (default: 10, max: 50) |

**Request Example:**
```http
GET /api/v1/search/recent?limit=10
X-User-Id: USR001
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "data": {
    "recentSearches": [
      {
        "id": "RS001",
        "query": "iphone 15 pro max",
        "searchedAt": "2024-01-15T10:30:00Z",
        "resultCount": 156,
        "filters": {
          "priceMin": 10000000,
          "freeShipping": true
        }
      },
      {
        "id": "RS002",
        "query": "macbook air",
        "searchedAt": "2024-01-14T15:45:00Z",
        "resultCount": 89,
        "filters": null
      },
      {
        "id": "RS003",
        "query": "airpods",
        "searchedAt": "2024-01-14T09:20:00Z",
        "resultCount": 234,
        "filters": {
          "ratingMin": 4
        }
      }
    ]
  }
}
```

**Error Response (401 Unauthorized):**
```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "msg": "User authentication required"
  }
}
```

## Acceptance Criteria

- [ ] Returns user's recent search queries in chronological order (newest first)
- [ ] Each entry includes query string, timestamp, and result count
- [ ] Filters used in the search are preserved
- [ ] Maximum 50 recent searches are stored per user
- [ ] Requires valid user authentication
- [ ] Recent searches older than 30 days are automatically removed
