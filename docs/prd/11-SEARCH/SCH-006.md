# SCH-006 - Clear Search History

## User Story

**As a** customer
**I want to** clear my search history
**So that** I can remove traces of my previous searches

## API

### DELETE /api/v1/search/history

Clear all search history for the current user.

**Headers:**

| Header | Type | Required | Description |
|--------|------|----------|-------------|
| X-User-Id | string | Yes | Authenticated user ID |

**Request Example:**
```http
DELETE /api/v1/search/history
X-User-Id: USR001
```

**Success Response (200 OK):**
```json
{
  "success": true,
  "data": {
    "deletedCount": 15,
    "msg": "Search history cleared successfully"
  }
}
```

**Error Response (401 Unauthorized):**
```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "msg": "User authentication required"
  }
}
```

## Acceptance Criteria

- [ ] All search history is deleted for the authenticated user
- [ ] Returns count of deleted searches
- [ ] Requires valid user authentication
- [ ] Returns success even if no history exists
- [ ] Operation is idempotent (safe to call multiple times)
