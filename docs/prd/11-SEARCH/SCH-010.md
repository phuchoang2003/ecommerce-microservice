# SCH-010 - Get Recommendations

## User Story

**As a** customer
**I want to** see personalized product recommendations
**So that** I can discover products I might like based on my preferences

## API

### GET /api/v1/search/recommendations

Get personalized product recommendations for the current user.

**Headers:**

| Header | Type | Required | Description |
|--------|------|----------|-------------|
| X-User-Id | string | Yes | Authenticated user ID |

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| limit | integer | No | Number of recommendations to return (default: 20, max: 50) |
| type | string | No | Recommendation type: personal, trending, new (default: personal) |

**Request Example:**
```http
GET /api/v1/search/recommendations?limit=20&type=personal
X-User-Id: USR001
```

## Acceptance Criteria

- [ ] Returns personalized recommendations based on user history
- [ ] Each product includes relevance score and reason
- [ ] Recommendations include browsing history, purchase history, and similar users
- [ ] Maximum 50 recommendations can be returned
- [ ] Response includes recommendation type and generation timestamp
- [ ] Non-authenticated users receive trending recommendations
- [ ] Recommendations refresh at least every 24 hours
