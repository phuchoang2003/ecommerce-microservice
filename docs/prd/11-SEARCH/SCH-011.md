# SCH-011 - Get Similar

## User Story

**As a** customer
**I want to** see products similar to one I am viewing
**So that** I can compare alternatives and find better options

## API

### GET /api/v1/search/similar/{productId}

Get products similar to a specified product.

**Path Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| productId | string | Yes | The product ID to find similar items for |

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| limit | integer | No | Number of similar products to return (default: 10, max: 50) |

**Request Example:**
```http
GET /api/v1/search/similar/P001?limit=10
```

## Acceptance Criteria

- [ ] Returns products similar to the specified product ID
- [ ] Similarity score indicates how closely products match
- [ ] Matched attributes explain why products are similar
- [ ] Results are sorted by similarity score (highest first)
- [ ] Maximum 50 similar products can be returned
- [ ] Returns 404 if product ID does not exist
- [ ] Similarity is based on category, price range, brand, and features
