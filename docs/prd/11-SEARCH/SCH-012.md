# SCH-012 - Get Trending Products

## User Story

**As a** customer
**I want to** see trending products
**So that** I can discover popular products that others are buying

## API

### GET /api/v1/search/trending-products

Get trending products based on search and sales activity.

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| limit | integer | No | Number of products to return (default: 20, max: 50) |
| categoryId | string | No | Filter by category ID |
| period | string | No | Time period: day, week, month (default: week) |

**Request Example:**
```http
GET /api/v1/search/trending-products?limit=20&period=week
```

## Acceptance Criteria

- [ ] Returns trending products sorted by trend score
- [ ] Each product includes rank, trend score, search volume, and sales volume
- [ ] Velocity indicator shows if trend is accelerating (fast, stable, slowing)
- [ ] Can filter by category ID
- [ ] Can specify time period (day, week, month)
- [ ] Maximum 50 products can be returned
- [ ] Results update at least every hour
