# SCH-013 - Get New Arrivals

## User Story

**As a** customer
**I want to** see newly added products
**So that** I can discover the latest products available in the store

## API

### GET /api/v1/search/new-arrivals

Get recently added products.

**Query Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| limit | integer | No | Number of products to return (default: 20, max: 50) |
| categoryId | string | No | Filter by category ID |
| days | integer | No | Products from the last N days (default: 7, max: 30) |

**Request Example:**
```http
GET /api/v1/search/new-arrivals?limit=20&days=7
```

## Acceptance Criteria

- [ ] Returns products sorted by creation date (newest first)
- [ ] Each product includes daysAgo indicating when it was added
- [ ] Can filter by category ID
- [ ] Can specify number of days to look back (max 30)
- [ ] Maximum 50 products can be returned
- [ ] New products without ratings show null rating
- [ ] Results include count of total new arrivals matching criteria
