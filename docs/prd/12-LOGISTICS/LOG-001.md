# LOG-001: Calculate Shipping Fee

## User Story
**As a** customer or internal service
**I want to** calculate shipping fees for my order
**So that** I can see the expected delivery cost before placing an order

## API Endpoint
```
POST /api/v1/logistics/shipping/calculate
```

### Request Body
```json
{
  "origin": {
    "postalCode": "10001",
    "country": "US"
  },
  "destination": {
    "postalCode": "90210",
    "country": "US"
  },
  "package": {
    "weight": 2.5,
    "length": 12,
    "width": 8,
    "height": 6,
    "unit": "in"
  },
  "carrierCode": "fedex",
  "serviceType": "ground"
}
```

### Response Body
```json
{
  "success": true,
  "data": {
    "carrier": "fedex",
    "serviceType": "ground",
    "baseFee": 8.99,
    "fuelSurcharge": 1.50,
    "totalFee": 10.49,
    "currency": "USD",
    "estimatedDeliveryDays": 5,
    "estimatedDeliveryDate": "2026-04-09"
  }
}
```

## Acceptance Criteria
- [ ] Calculate shipping fee based on origin, destination, and package dimensions
- [ ] Apply carrier-specific pricing rules
- [ ] Include fuel surcharge in total calculation
- [ ] Return estimated delivery date based on service type
- [ ] Support multiple carriers (fedex, ups, usps)
- [ ] Validate package weight and dimensions against carrier limits
- [ ] Return error for invalid postal codes or unsupported destinations
