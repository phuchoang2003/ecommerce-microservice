# LOG-002: Get Shipping Rates

## User Story
**As a** customer
**I want to** compare shipping rates from multiple carriers
**So that** I can choose the best option for my budget and delivery time

## API Endpoint
```
GET /api/v1/logistics/shipping/rates
```

### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| originPostalCode | string | Yes | Origin postal code |
| originCountry | string | Yes | Origin country code |
| destPostalCode | string | Yes | Destination postal code |
| destCountry | string | Yes | Destination country code |
| weight | number | Yes | Package weight |
| length | number | No | Package length |
| width | number | No | Package width |
| height | number | No | Package height |
| unit | string | No | Dimension unit (in/cm), default: in |

## Acceptance Criteria
- [ ] Return rates from multiple carriers in a single response
- [ ] Sort rates by total fee ascending by default
- [ ] Support filtering by specific carrier
- [ ] Include estimated delivery date for each rate
- [ ] Cache carrier rate queries for performance
- [ ] Return error for invalid or unsupported routes
