# LOG-005: Report Issue

## User Story
**As a** customer
**I want to** report an issue with my shipment
**So that** I can get help with lost, damaged, or delayed packages

## API Endpoint
```
POST /api/v1/logistics/tracking/{trackingNumber}/issue
```

### Path Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| trackingNumber | string | The carrier tracking number |

### Request Body
```json
{
  "issueType": "not_received",
  "description": "Package shows delivered but I did not receive it",
  "reportedBy": {
    "type": "customer",
    "id": "cust_12345"
  },
  "contactEmail": "customer@example.com",
  "attachments": [
    {
      "type": "image",
      "url": "https://storage.example.com/evidence/photo1.jpg"
    }
  ]
}
```

### Response Body
```json
{
  "success": true,
  "data": {
    "caseId": "case_789xyz",
    "trackingNumber": "1Z999AA10123456784",
    "issueType": "not_received",
    "status": "opened",
    "createdAt": "2026-04-04T14:30:00Z",
    "estimatedResolution": "2026-04-06"
  }
}
```

### Issue Types
| Code | Description |
|------|-------------|
| not_received | Package shows delivered but recipient did not receive it |
| damaged | Package or contents arrived damaged |
| lost | Package has not been delivered and tracking shows no activity |
| wrong_item | Different item than what was ordered |
| delayed | Package is significantly later than estimated delivery |

## Acceptance Criteria
- [ ] Create support case for reported issue
- [ ] Validate tracking number exists
- [ ] Accept issue type from predefined list
- [ ] Support optional evidence attachments
- [ ] Link case to customer account
- [ ] Send notification to support team
- [ ] Return case ID for tracking
- [ ] Prevent duplicate open cases for same tracking number
