# LOG-006: Get Delivery Proof

## User Story
**As a** seller or customer
**I want to** obtain proof of delivery
**So that** I can confirm a package was delivered and see who signed for it

## API Endpoint
```
GET /api/v1/logistics/tracking/{trackingNumber}/proof
```

### Path Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| trackingNumber | string | The carrier tracking number |

### Response Body
```json
{
  "success": true,
  "data": {
    "trackingNumber": "1Z999AA10123456784",
    "carrier": "ups",
    "deliveryStatus": "delivered",
    "deliveryDate": "2026-04-04T13:45:00Z",
    "deliveryDateFormatted": "April 4, 2026",
    "signedBy": "JOHN DOE",
    "deliveryLocation": {
      "address": "123 Main Street",
      "city": "Beverly Hills",
      "state": "CA",
      "postalCode": "90210",
      "country": "US"
    },
    "proofImageUrl": "https://logistics.example.com/proof/1Z999AA10123456784.pdf",
    "proofDownloadUrl": "https://logistics.example.com/proof/1Z999AA10123456784/download",
    "obtainedAt": "2026-04-04T14:00:00Z"
  }
}
```

## Acceptance Criteria
- [ ] Return delivery proof only for delivered packages
- [ ] Include signed by information when available
- [ ] Provide downloadable proof document URL
- [ ] Validate tracking number exists
- [ ] Return 404 if delivery not yet completed
- [ ] Cache proof data to reduce carrier API calls
- [ ] Include delivery location details
