# LOG-011: Regenerate Label

## User Story
**As a** seller or fulfillment system
**I want to** regenerate a shipping label
**So that** I can get a new label if the original was lost or damaged

## API Endpoint
```
POST /api/v1/logistics/labels/{labelId}/regenerate
```

### Path Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| labelId | string | The original label ID |

### Request Body
```json
{
  "reason": "label_damaged",
  "keepTrackingNumber": true
}
```

### Response Body
```json
{
  "success": true,
  "data": {
    "labelId": "lbl_def456",
    "originalLabelId": "lbl_abc123",
    "trackingNumber": "794644790234",
    "carrier": "fedex",
    "serviceType": "ground",
    "labelUrl": "https://logistics.example.com/labels/lbl_def456.pdf",
    "labelFormat": "PDF",
    "labelSize": "4x6",
    "createdAt": "2026-04-04T15:00:00Z",
    "expiresAt": "2026-04-11T15:00:00Z",
    "previousLabelStatus": "expired",
    "rate": {
      "baseFee": 8.99,
      "fuelSurcharge": 1.50,
      "totalFee": 10.49,
      "currency": "USD"
    }
  }
}
```

### Regeneration Reasons
| Code | Description |
|------|-------------|
| label_damaged | Original label was damaged and unreadable |
| label_lost | Original label was lost |
| incorrect_address | Original label had wrong address |
| carrier_change | Switching to a different carrier |

## Acceptance Criteria
- [ ] Generate new label based on original label data
- [ ] Option to keep or generate new tracking number
- [ ] Invalidate original label after regeneration
- [ ] Track regeneration history
- [ ] Charge any price difference if applicable
- [ ] Return 404 if original label not found
- [ ] Return 400 if label cannot be regenerated (e.g., already voided)
