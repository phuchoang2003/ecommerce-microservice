# LOG-012: Void Label

## User Story
**As a** seller or fulfillment system
**I want to** void a shipping label
**So that** I can cancel a shipment before pickup

## API Endpoint
```
POST /api/v1/logistics/labels/{labelId}/void
```

### Path Parameters
| Parameter | Type | Description |
|-----------|------|-------------|
| labelId | string | The label ID to void |

### Request Body
```json
{
  "reason": "order_cancelled"
}
```

### Response Body
```json
{
  "success": true,
  "data": {
    "labelId": "lbl_abc123",
    "trackingNumber": "794644790234",
    "status": "voided",
    "voidedAt": "2026-04-04T14:30:00Z",
    "reason": "order_cancelled",
    "refund": {
      "status": "pending",
      "amount": 10.49,
      "currency": "USD",
      "estimatedProcessingDays": 3
    }
  }
}
```

### Void Reasons
| Code | Description |
|------|-------------|
| order_cancelled | Order was cancelled by customer |
| address_incorrect | Shipping address was incorrect |
| item_out_of_stock | Item no longer available |
| customer_request | Customer requested cancellation |
| duplicate_label | Label was created twice |

## Acceptance Criteria
- [ ] Void label with carrier system
- [ ] Prevent voiding labels that have been used (scanned)
- [ ] Release tracking number back to pool if applicable
- [ ] Initiate refund process for paid labels
- [ ] Track void reason for analytics
- [ ] Return 400 if label already scanned or in transit
- [ ] Return 404 if label not found
- [ ] Send notification to fulfillment system
