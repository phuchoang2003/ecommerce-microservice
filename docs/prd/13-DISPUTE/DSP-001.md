# DSP-001: Create Dispute

## User Story
**As a** Buyer
**I want to** create a dispute for an order
**So that** I can request resolution for an issue with my order

A buyer can create a dispute within 7 days of order delivery.

## API

**Endpoint:** `POST /api/v1/disputes`

### Request Body
```json
{
  "orderId": "string",
  "reason": "string",
  "description": "string",
  "requestedResolution": "REFUND | REPLACEMENT | RETURN"
}
```

### Response (201 Created)
```json
{
  "id": "string",
  "orderId": "string",
  "buyerId": "string",
  "status": "OPEN",
  "reason": "string",
  "description": "string",
  "requestedResolution": "REFUND",
  "createdAt": "2026-04-04T10:00:00Z"
}
```

## Acceptance Criteria

- [ ] Buyer can create a dispute for an order they purchased
- [ ] Dispute can only be created within 7 days of delivery
- [ ] Dispute is created with status OPEN
- [ ] Order must be in DELIVERED status
- [ ] Buyer cannot create multiple disputes for the same order
- [ ] System returns 400 if order is not eligible for dispute
- [ ] System returns 404 if order does not exist
