# DSP-002: List My Disputes

## User Story
**As a** Buyer
**I want to** list all my disputes
**So that** I can track the status of my dispute cases

## API

**Endpoint:** `GET /api/v1/disputes`

### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| status | string | No | Filter by status: OPEN, UNDER_REVIEW, RESOLVED, CANCELLED |
| page | int | No | Page number (default: 0) |
| size | int | No | Page size (default: 20) |

### Response (200 OK)
```json
{
  "content": [
    {
      "id": "string",
      "orderId": "string",
      "status": "OPEN",
      "reason": "string",
      "requestedResolution": "REFUND",
      "createdAt": "2026-04-04T10:00:00Z"
    }
  ],
  "totalElements": 100,
  "totalPages": 5,
  "number": 0,
  "size": 20
}
```

## Acceptance Criteria

- [ ] Returns only disputes belonging to the authenticated buyer
- [ ] Supports pagination
- [ ] Supports filtering by status
- [ ] Results are ordered by createdAt descending
- [ ] Returns empty list if no disputes found
