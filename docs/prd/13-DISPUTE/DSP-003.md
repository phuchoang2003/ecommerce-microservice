# DSP-003: Get Dispute

## User Story
**As a** Buyer or Seller
**I want to** get details of a specific dispute
**So that** I can view the full information and history of a dispute case

## API

**Endpoint:** `GET /api/v1/disputes/{disputeId}`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

## Acceptance Criteria

- [ ] Buyer can view their own dispute details
- [ ] Seller can view dispute details for their order
- [ ] Returns full dispute history including evidence and responses
- [ ] Returns 403 if user is not authorized to view this dispute
- [ ] Returns 404 if dispute does not exist
