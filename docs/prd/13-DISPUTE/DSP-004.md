# DSP-004: Add Evidence

## User Story
**As a** Buyer or Seller
**I want to** add evidence to a dispute
**So that** I can support my case with relevant documents or images

## API

**Endpoint:** `POST /api/v1/disputes/{disputeId}/evidence`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Request Body
```json
{
  "type": "IMAGE | DOCUMENT",
  "url": "string",
  "description": "string"
}
```

### Response (201 Created)
```json
{
  "id": "string",
  "disputeId": "string",
  "type": "IMAGE",
  "url": "string",
  "description": "string",
  "uploadedBy": "string",
  "uploadedAt": "2026-04-04T10:00:00Z"
}
```

## Acceptance Criteria

- [ ] Buyer can add evidence to their own dispute
- [ ] Seller can add evidence to disputes on their orders
- [ ] Evidence types can be IMAGE or DOCUMENT
- [ ] Evidence is timestamped with upload time
- [ ] Cannot add evidence to RESOLVED or CANCELLED disputes
- [ ] Returns 403 if user is not authorized
- [ ] Returns 404 if dispute does not exist
