# DSP-005: Cancel Dispute

## User Story
**As a** Buyer
**I want to** cancel my dispute
**So that** I can withdraw a dispute if the issue was resolved otherwise

## API

**Endpoint:** `DELETE /api/v1/disputes/{disputeId}`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Response (200 OK)
```json
{
  "id": "string",
  "status": "CANCELLED",
  "cancelledAt": "2026-04-04T10:00:00Z",
  "cancelledBy": "string"
}
```

## Acceptance Criteria

- [ ] Buyer can cancel their own dispute
- [ ] Dispute status changes to CANCELLED
- [ ] Only disputes with status OPEN can be cancelled
- [ ] Returns 400 if dispute is not in OPEN status
- [ ] Returns 403 if buyer does not own the dispute
- [ ] Returns 404 if dispute does not exist
