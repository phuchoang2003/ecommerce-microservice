# DSP-010: Seller Respond

## User Story
**As a** Seller
**I want to** respond to a dispute
**So that** I can provide my side of the story and relevant information

## API

**Endpoint:** `PUT /api/v1/disputes/{disputeId}/respond`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Request Body
```json
{
  "response": "string"
}
```

### Response (200 OK)
```json
{
  "id": "string",
  "sellerResponse": {
    "response": "string",
    "respondedAt": "2026-04-04T11:00:00Z"
  },
  "status": "UNDER_REVIEW"
}
```

## Acceptance Criteria

- [ ] Seller can respond to disputes on their orders
- [ ] Dispute status changes to UNDER_REVIEW after response
- [ ] Seller can only respond once (cannot update response)
- [ ] Cannot respond to disputes not in OPEN status
- [ ] Returns 403 if seller does not own the order
- [ ] Returns 404 if dispute does not exist
