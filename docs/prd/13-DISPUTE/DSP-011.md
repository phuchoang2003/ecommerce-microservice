# DSP-011: Seller Propose Resolution

## User Story
**As a** Seller
**I want to** propose a resolution to the dispute
**So that** I can offer an acceptable solution to the buyer

## API

**Endpoint:** `PUT /api/v1/disputes/{disputeId}/propose-resolution`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Request Body
```json
{
  "type": "REFUND | REPLACEMENT | PARTIAL_REFUND",
  "amount": 50.00,
  "msg": "string"
}
```

### Response (200 OK)
```json
{
  "id": "string",
  "proposedResolution": {
    "type": "PARTIAL_REFUND",
    "amount": 50.00,
    "msg": "string",
    "proposedAt": "2026-04-04T11:00:00Z"
  },
  "status": "UNDER_REVIEW"
}
```

## Acceptance Criteria

- [ ] Seller can propose resolution for disputes on their orders
- [ ] Seller can propose REFUND, REPLACEMENT, or PARTIAL_REFUND
- [ ] For PARTIAL_REFUND, amount must be specified
- [ ] Proposal updates dispute status to UNDER_REVIEW
- [ ] Seller can update their proposal (newer one replaces older)
- [ ] Returns 403 if seller does not own the order
- [ ] Returns 404 if dispute does not exist
