# DSP-012: Seller Request Extension

## User Story
**As a** Seller
**I want to** request an extension to respond to a dispute
**So that** I have more time to gather information or documents

## API

**Endpoint:** `PUT /api/v1/disputes/{disputeId}/request-extension`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Request Body
```json
{
  "reason": "string"
}
```

### Response (200 OK)
```json
{
  "id": "string",
  "extensionRequest": {
    "reason": "string",
    "requestedAt": "2026-04-04T11:00:00Z",
    "status": "PENDING"
  }
}
```

## Acceptance Criteria

- [ ] Seller can request extension for disputes on their orders
- [ ] Extension request is created with PENDING status
- [ ] Seller can only request one extension per dispute
- [ ] Cannot request extension if dispute is not in OPEN status
- [ ] Returns 403 if seller does not own the order
- [ ] Returns 404 if dispute does not exist
