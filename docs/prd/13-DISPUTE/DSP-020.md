# DSP-020: Admin List Disputes

## User Story
**As an** Admin
**I want to** list all disputes in the system
**So that** I can manage and monitor dispute cases

## API

**Endpoint:** `GET /api/v1/admin/disputes`

### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| status | string | No | Filter by status: OPEN, UNDER_REVIEW, ESCALATED, RESOLVED, CANCELLED |
| disputeId | string | No | Filter by specific dispute ID |
| buyerId | string | No | Filter by buyer ID |
| sellerId | string | No | Filter by seller ID |
| page | int | No | Page number (default: 0) |
| size | int | No | Page size (default: 20) |

### Response (200 OK)
```json
{
  "content": [
    {
      "id": "string",
      "orderId": "string",
      "buyerId": "string",
      "sellerId": "string",
      "status": "ESCALATED",
      "reason": "string",
      "requestedResolution": "REFUND",
      "createdAt": "2026-04-04T10:00:00Z"
    }
  ],
  "totalElements": 100,
  "totalPages": 5,
  "number": 0,
  "size": 20
}
```

## Acceptance Criteria

- [ ] Admin can view all disputes in the system
- [ ] Supports multiple filter criteria
- [ ] Supports pagination
- [ ] Results are ordered by createdAt descending
- [ ] Only accessible by users with ADMIN role
- [ ] Returns empty list if no disputes match filters
