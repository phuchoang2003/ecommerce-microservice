# DSP-021: Admin Get Dispute

## User Story
**As an** Admin
**I want to** get full details of any dispute
**So that** I can review all information needed for resolution

## API

**Endpoint:** `GET /api/v1/admin/disputes/{disputeId}`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

## Acceptance Criteria

- [ ] Admin can view any dispute in the system
- [ ] Returns complete dispute information including timeline

- [ ] Returns 404 if dispute does not exist
