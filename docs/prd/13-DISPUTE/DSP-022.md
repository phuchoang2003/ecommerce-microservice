# DSP-022: Admin Escalate Dispute

## User Story
**As an** Admin
**I want to** escalate a dispute
**So that** it can be handled by a senior specialist or management

## API

**Endpoint:** `PUT /api/v1/admin/disputes/{disputeId}/escalate`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Request Body
```json
{
  "reason": "string",
  "priority": "HIGH | CRITICAL"
}
```

### Response (200 OK)
```json
{
  "id": "string",
  "status": "ESCALATED",
  "escalation": {
    "reason": "string",
    "priority": "HIGH",
    "escalatedAt": "2026-04-04T12:00:00Z",
    "escalatedBy": "string"
  }
}
```

## Acceptance Criteria

- [ ] Admin can escalate disputes in OPEN or UNDER_REVIEW status
- [ ] Escalation updates status to ESCALATED
- [ ] Escalation includes reason and priority level
- [ ] Escalation is timestamped
- [ ] Cannot escalate already RESOLVED or CANCELLED disputes
- [ ] Only accessible by users with ADMIN role
- [ ] Returns 404 if dispute does not exist
