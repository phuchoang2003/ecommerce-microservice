# DSP-023: Admin Resolve Dispute

## User Story
**As an** Admin
**I want to** resolve a dispute
**So that** the dispute can be closed with a final decision

## API

**Endpoint:** `PUT /api/v1/admin/disputes/{disputeId}/resolve`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Request Body
```json
{
  "resolution": "string",
  "decision": "FULL_REFUND | PARTIAL_REFUND | REPLACEMENT | REJECTED",
  "amount": 50.00
}
```

### Response (200 OK)
```json
{
  "id": "string",
  "status": "RESOLVED",
  "adminResolution": {
    "resolution": "string",
    "decision": "PARTIAL_REFUND",
    "amount": 50.00,
    "resolvedAt": "2026-04-04T12:00:00Z",
    "resolvedBy": "string"
  }
}
```

## Acceptance Criteria

- [ ] Admin can resolve disputes in any status except CANCELLED
- [ ] Resolution includes final decision and amount (if applicable)
- [ ] Dispute status changes to RESOLVED
- [ ] Resolution is timestamped with admin ID
- [ ] Resolved disputes trigger appropriate actions (refund, replacement)
- [ ] Only accessible by users with ADMIN role
- [ ] Returns 404 if dispute does not exist
