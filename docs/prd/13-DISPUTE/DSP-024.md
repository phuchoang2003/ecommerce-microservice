# DSP-024: Process Refund

## User Story
**As an** Admin
**I want to** process a refund for a resolved dispute
**So that** the buyer receives their money back according to the resolution

## API

**Endpoint:** `POST /api/v1/admin/disputes/{disputeId}/refund`

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| disputeId | string | Yes | The dispute ID |

### Request Body
```json
{
  "amount": 50.00,
  "reason": "string"
}
```

### Response (200 OK)
```json
{
  "id": "string",
  "refundId": "string",
  "disputeId": "string",
  "amount": 50.00,
  "status": "PROCESSED",
  "processedAt": "2026-04-04T12:00:00Z",
  "processedBy": "string"
}
```

## Acceptance Criteria

- [ ] Admin can process refund for resolved disputes
- [ ] Refund amount cannot exceed the resolution amount
- [ ] Refund is linked to the dispute for tracking
- [ ] Refund status is updated upon processing
- [ ] Integration with payment service to process actual refund
- [ ] Only accessible by users with ADMIN role
- [ ] Returns 400 if dispute is not in RESOLVED status
- [ ] Returns 404 if dispute does not exist
